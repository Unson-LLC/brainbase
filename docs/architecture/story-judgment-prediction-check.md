# 予測の確認の配置

予測の確認は、既存の判断の枠組みの記録（`judgment-frame-record.v1`）の、予測のuseに付く任意の欄として持つ。記録の版は変えない。確認の欄を持たない記録の動作は従来どおりで、予測は未確認として数える。

止めるのは、採用案が確かめて外れた予測に頼るときだけにする（`chosen_relies_on_failed_prediction`）。未確認は止めず、記録の応答に件数を返す。どの判断で確認を必須にするかは、hostの方針として扱う。hostは、useに未知の欄があると記録を不成功にするので、このsource変更より先にhost側で受け付ける必要がある。このsource変更はpackageのversionを変更しない。
