# ADR: knowledge_eventを記憶循環の共通入力契約にする

- 日付: 2026-08-13
- 状態: 採用

## 決定

議事録、外部ランナー、完了済みjudgment episodeを`knowledge_event.v1`へ正規化し、不変イベント、Episode、Memory Promotion Kernel、Graphを一つの処理として接続する。

Resolverは参照先を決める読込み側のコントロールプレーンであり、Graph書込みや外部作用の許可には使わない。書込み先は出典、決定権、適用範囲、競合、機密性をコードで判定する。

## 保存境界

- Ledger: 本文ハッシュ、時刻、発生元、主体、権限スナップショット、正本ポインタを持つ不変イベント包絡
- Episode: 会議、判断、実行を束ねる安定ID
- Candidate Store: 処理段階、意味状態、保存先の唯一の更新境界
- Graph: 現在有効な組織判断と出典ポインタ。議事録全文は保存しない
- Skill候補: 複数Episodeで有効性を確認する後続処理

## 原子性と訂正

イベント、候補、Graph現在状態、検索対象の更新は同一Postgresトランザクションで行う。訂正は破壊的削除ではなく新イベントで記録し、旧候補を`superseded`または`retracted`へ移す。

`knowledge_cycle_receipt.v1`はイベントと段階履歴から生成する読取モデルとし、新しいReceipt正本テーブルは作らない。

## 外部作用

タスク作成、割当、送信、公開、購入、デプロイは本処理から実行しない。候補の保存だけを自動化する。

## 非目標

- Eveの復活
- Graphを原文保管庫として使うこと
- 時刻だけで競合を解決すること
