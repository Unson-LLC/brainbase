# 判断の枠組みの本文取得の配置

共通の本文取得・カタログ照合をOSS正本に置き、既存 `judgment-frame` subpathから公開する。テナント側に同じ実装をコピーしない。

handlerは保存先を所有しない。既存のJudgmentFrameRecordsPageを返すloadRecordsを依存として受け取り、呼出し側の認可済み保存先だけを読む。本文・版・意味的な適用範囲は返すが、認可範囲を適用範囲とみなさない。

利用側は公開版の依存に切り替えてから、Hostの本文取得必須化と同時に反映する。このsource変更はpackageのversionを変更せず、公開と稼働反映は別の手順で行う。
