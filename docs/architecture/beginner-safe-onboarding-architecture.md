# 初心者向けオンボーディング投影 Architecture

親 Story: [初心者が安心して完了できるオンボーディング](../stories/beginner-safe-onboarding-story.md)

## 境界

- オントロジー正本とオンボーディング実行状態は変更しない。
- MCP の結果投影層が、正本の状態から初心者向け案内を生成する。
- 初心者向け案内は生の実行状態より先に提示し、詳細は監査可能な形で残す。
- 変更内容・可逆性・復旧方法は、状態遷移に対応する案内として投影する。
- アクセシビリティ評価の証拠境界は製品投影と分離し、未検証条件を成功に昇格させない。

## データの流れ

1. オンボーディング実行状態または Ontology 1.0.0 の正本を読む。
2. 投影層が日本語の現在地、次の一手、安全確認、業務例を付加する。
3. MCP クライアントは初心者向け案内を先に、正式な状態・契約を後に表示する。
4. 評価成果物は実画面証拠とペルソナ固有の反応を分けて記録する。
