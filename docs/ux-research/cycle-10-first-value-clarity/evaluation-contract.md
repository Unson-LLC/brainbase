# Cycle 10: 初回価値の明瞭さ

## 北極星

初めてBrainbaseを導入した人が、取得開始から10分以内に、保存したプロジェクト、関係者、判断基準が現実の依頼へつながった短い実回答を読み、「こう使える」と認識できる。

## 固定条件

- 開始: 候補tarballのfresh install開始
- 完了: 実Codexが実MCPの`resolve_entity`、`get_context`、`search`を使い、保存済み文脈を反映した回答を返す
- 予算: 600,000ms
- 初回回答: 「覚えていたこと」「つながったこと」「次にできること」の順、表なし
- 技術監査: 正規IDと関係経路はtool結果で保持し、初回本文の理解を妨げない
- データ: 架空のAtlas導入、田中、判断基準のみ

## 合成価値評価

32の独立ペルソナへ同じ不変コーパスを渡し、役割固有の有用差分、価値認識点、再利用意向、予算内かを判定させる。人間観察、実機、支援技術、公開registryは別の証拠境界であり、それらが未収集という理由だけで合成判定を`uncertain`へ下げない。

収束条件は32/32が`recognized`、予算内、再利用意向`yes`、新規Major 0件。
