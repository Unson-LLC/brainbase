# cycle-07 UX改善結果

## 結論

公開CLIの候補ジャーニーは、隔離環境への導入開始から実CodexがBrainbase MCPを使った回答を返すまで35,789msで通過した。ただし、実在利用者本人の価値認識は収集していないため、「10分で初回価値を達成した」とは判定しない。

## 今回変えたこと

- `onboard:demo`を初回価値や完了ではなく、接続前の任意プレビューとして表示する。
- 初回導線を、最小文脈保存、MCP設定反映、新しい実エージェントでの現実依頼、本人の価値判断という順序へ変更する。
- `doctor`と内部状態で、ローカル準備、実MCP未確認、運用未完了、人間の価値未観察を分離する。
- README、初回価値ガイド、クイックスタート、MCP導入、CLIリファレンスを同じ定義へ揃える。
- プロジェクト規約と生成オンボーディングSkillへ、人間の価値認識なしに10分達成を主張しない規則を追加する。

## 実測

- ローカルtarballを隔離consumerへ導入: 成功
- 表示された`onboard:seed`を実行: 成功
- MCP設定プレビューを隔離したCodex起動へ適用: 成功
- 実Codex: exit 0
- Brainbase MCP: `get_context`と`search`を実呼び出し
- 実回答: 保存済み事実、未確認事項、次に合意すること、利用した文脈を分離
- 候補ジャーニー: 35,789ms / 600,000ms
- 本人の価値認識: `not_collected`
- 初回価値達成: `false`

## 2ラウンド、各32ペルソナ評価

第1ラウンドと、0.2.2候補を再収集した第2ラウンドで、それぞれ32の独立した合成ペルソナを評価した。両ラウンドとも、次操作、非破壊な最小文脈保存、実MCP利用、事実と未確認事項の分離を一貫して支持した。全ペルソナで、本人の価値判断と不足時の再試行は未収集だった。

ハードゲートの「本人観察なしに達成を主張しない」は通過している。北極星そのものの達成は未確認である。この二つを混同しない。

## 残る境界

- 実在の初見利用者による導入開始からの観察
- 回答を見た本人の「役立った」という確認
- 役立たなかった場合に不足文脈だけを追加する再試行
- npm production registryからの現行変更版取得
- 利用者の永続設定へMCP設定を反映して再起動する経路
- 実機の音声入力、スクリーンリーダー、外部参照元

これらを収集するまで、人間の10分初回価値について収束を主張しない。
