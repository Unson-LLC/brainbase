# cycle-07 人間の初回価値 評価契約

## 北極星

初見の利用者が公開Brainbaseの取得・導入を始めてから10分以内に、実際の対象エージェントが本人承認済みの文脈を使って現実の依頼へ有用な回答を返し、その回答を見た利用者本人が「Brainbaseはこう使える」と価値を認識する。

CLIコマンドの応答時間、`ready: true`、CLIサンプル、エージェントが書いた成功マーカー、合成ペルソナの評価だけでは、この北極星を達成したことにしない。

## 固定ジャーニー

1. 配布tarballを新しい利用環境へインストールする。
2. `brainbase onboard:start` から表示された最小文脈登録へ進む。
3. 本人、仕事、関係者、判断基準を本人承認済みのfixtureとして保存する。
4. `brainbase onboard:install --target codex --dry-run` の設定を隔離したCodex起動へ反映する。
5. 新しい実Codexへ現実の依頼を送り、Brainbase MCPの `get_context` と `search` を使わせる。
6. 実回答、使った文脈、未確認事項を利用者へ示す。
7. 利用者本人へ「役立ったか」を確認する。

開始標識は1のインストール開始直前、候補価値標識は6の実回答完了、達成標識は7で本人が価値を認識した時点とする。予算は600,000ms。

## 証拠区分

- `candidate_end_to_end_journey`: 1から6を実プロセスで完了した証拠
- `human_value_recognition`: 7の本人観察。収集していなければ `not_collected`
- `synthetic_persona_evaluation`: 固定した同一証拠を独立ペルソナが評価した結果。人間観察の代用不可
- `production_registry_install`: npm公開版を取得した証拠。ローカルtarballと区別する

## 共通タスク

1. 初回出力から、次に行う操作を迷わず特定する。
2. 最小文脈を安全に保存し、既存データを失わない。
3. MCP設定を反映した新しい実エージェントで現実の依頼を実行する。
4. 実回答が使った保存文脈と未確認事項を区別する。
5. 本人が価値を判断し、足りなければ不足文脈だけを追加して再試行する。

## ハードゲート

- 未設定、接続前、未確認を成功や完了と表示しない。
- すべての主要状態に、次の操作または復旧操作を示す。
- 公開表示した必須コマンドが同じ隔離環境で実行できる。
- 既存データを暗黙に削除または別データで上書きしない。
- 実エージェントがBrainbase MCPを使った証拠なしに初回価値を主張しない。
- 人間本人の価値認識なしに「10分で初回価値を達成」と主張しない。
- 主要説明を理解可能な日本語で示す。

## 境界

このサイクルの自動実行は、隔離したローカルtarball、fixture文脈、実Codex、実MCP呼び出しを対象とする。実在の初見利用者、本人の価値認識、実機支援技術、production registryの更新、外部データソース、外部副作用は、別の証拠がない限り `not_collected` とする。
