# cycle-06 CLI初回価値 評価契約

## 北極星

初見の利用者が、内部APIを知らずに公開CLIだけで安全に最小文脈を登録し、10分以内に「保存文脈がどう役立つか」を明示されたCLIサンプルで確認できる。

このCLIフェーズでは、実エージェント接続や実LLM応答を初回価値へ数えない。実エージェントから同じ依頼を実行した価値は別フェーズであり、今回は `not_collected` とする。

## 固定する公開経路

ローカルチェックアウト向けにREADMEが案内する、次の実プロセスを使う。

1. `npm run onboard:start -- ...`
2. `npm run onboard:seed -- ...`
3. `npm run onboard:demo -- ...`
4. `npm run doctor -- ...`

関数の直接呼び出し、テスト内のハンドラー呼び出し、`ready=true`、終了コード0だけではCLIフェーズの初回価値と数えない。開始標識は1の子プロセス起動直前、価値標識は3の標準出力に、保存したプロジェクト・関係者・判断基準を使い、かつ実エージェント応答ではないと明示したサンプル本文が出た時点とする。予算は600,000ms。

## 共通タスク

1. 初回開始の出力から、次にコピーして実行するコマンドを一つ選ぶ。
2. 名前、価値観、プロジェクト、関係者、判断基準を保存する。
3. 保存した文脈を使った相談メモを表示し、どの保存内容が反映されたか説明する。
4. 未設定、不正入力、既存状態から、安全に次の操作または再開方法を特定する。

## 状態遷移セル

| 開始状態 | 主要操作 | 完了条件 |
|---|---|---|
| 空 | `onboard:start` | 最初に実行すべきコピー可能なコマンドが見える |
| 空 | `onboard:demo` | 未設定を成功扱いせず、最小の復旧操作が見える |
| 空 | 不正な `onboard:seed` | 非0終了し、入力形式と再実行方法が分かる |
| 最小文脈あり | `onboard:demo` | 保存文脈を使った有用な本文が見える |
| 最小文脈あり | `doctor --format json` | 準備状態を機械可読に確認できる |
| 既存状態 | `onboard:start` と再度 `onboard:demo` | データを失わず再開できる |

## ハードゲート

- 未設定や失敗を成功と表示しない。
- 出力に次の操作または復旧操作がない状態を作らない。
- 公開出力のコマンドが、その実行環境でコピーして動かない状態を残さない。
- 既存データを暗黙に上書きまたは削除しない。
- 初回価値を、設定完了・終了コード・内部状態だけで代用しない。
- 利用者向け日本語の中に、理解を妨げる未翻訳の主要説明を残さない。

## 証拠区分と境界

- `source_inspection`: CLI、README、テストの確認
- `automated_test`: 型検査、対象テスト、実プロセス統合テスト
- `synthetic_cli_evaluation`: 固定した同一端末コーパスを32の独立ペルソナが解釈
- `human_observation`: `not_collected`
- `real_device_evidence`: `not_collected`
- `assistive_technology_evidence`: `not_collected`
- `production_install_evidence`: `not_collected`

## 今回の対象外

ホスト型サービス、実在利用者調査、本番資格情報、外部ソース接続、管理画面、ドメインの保存方針変更は扱わない。
