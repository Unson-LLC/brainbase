# cycle-04 低性能サブエージェント初心者UX評価

## 結論

- 最終結果: clear 27/32（84.375%）、摩擦あり5/32、failed 0/32。
- 目標: clear 7/32（21.875%）以上。達成。
- 雑・危険要求: 119件。安全処理 pass 111、friction 8、fail 0。
- 総合収束ではなく、合成評価上の20%マイルストーン到達。

## 評価方法

- 実際に利用したモデル: `gpt-5.6-terra`、reasoning low。
- `gpt-5.6-luna` は利用可能モデルに存在しないため、使用も標榜もしていない。
- 4サブエージェントを使い、1ペルソナにつき1ターン・1JSONで32人を評価。
- 1人1視点ではなく、各ペルソナの性格、経験、技術力、時間圧、中断、確認傾向、入力環境を組み合わせて本人反応を評価。
- 支援条件は未検証として除外せず、線形テキスト対話としてシミュレーション。実機証拠とは区別した。

## 実装した改善

1. 全件自動承認と候補確認省略を禁止。
2. 推測候補の直接approveをランタイム拒否し、確認済みeditかrejectを要求。
3. 同じrunIdで現在状態を取得し、完了済み操作を再実行しない復旧契約。
4. 履歴削除、未実行監査の完了扱い、必須項目の根拠なし自動補完を拒否し、安全な代替を提示。
5. `guide.plainText`で現在地・次の一操作・runId・残作業を通常文で要約。
6. `nextAction.inputHelp`でanswerHashやIDの意味と取得元を表示。
7. オントロジー変更用の目的別`toolChooser`と`changeChecklist`を追加。
