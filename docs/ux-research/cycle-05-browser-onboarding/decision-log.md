# 判断ログ

## 2026-08-17: 最短導線を一枚追加する

- 悩み: 既存文書には必要情報があるため、説明の書き直しだけでは中断時の負担が下がらない。
- 判断: 詳細ページを正本として残し、トップから直接入れる再開可能なチェックリストを追加する。
- 根拠: Round 1の22/32人が、ページ横断、現在地、再開位置のいずれかを摩擦として明示した。
- 影響: 初回利用者は一枚を進行表として使い、詳細が必要なときだけ既存ページへ移動できる。

## 2026-08-17: 設定統合は自動化しない

- 悩み: 手動統合は摩擦だが、利用者の既存MCP設定やHookを壊す危険がある。
- 判断: dry-runと別出力を維持し、バックアップ、追加対象、元へ戻す条件を近接して説明する。
- 根拠: 31/32人が非上書き境界を安全性の根拠として確認した。
- 影響: 手数は残るが、速度のために安全境界を弱めない。

## 2026-08-17: 404はfaviconだけを修正する

- 悩み: 一部評価は末尾スラッシュなしのガイドURLも404と記録した。
- 判断: 独立再現できた `/favicon.ico` の404だけを修正し、ガイドURLは変更しない。
- 根拠: `/guide/onboarding-process`、`/guide/getting-started`、`/guide/mcp-install`、`/guide/judgment-audit` は末尾スラッシュの有無どちらもHTTP 200を再確認した。`/favicon.ico` はHTTP 404を再現した。
- 影響: 未再現の推測修正を避け、観測されたコンソールエラーの原因だけを除く。

## 2026-08-17: 空表示のフォーカス対象は重大ゲートにしない

- 悩み: 空テキストのテーマボタンやGitHubリンクが報告された。
- 判断: 現時点ではVitePress既定UIを変更しない。
- 根拠: テーマボタンには`title`、GitHubリンクとナビゲーションボタンには`aria-label`、見出しリンクには`aria-label`があり、名前のない主要操作は再現しなかった。実スクリーンリーダーは未確認。
- 影響: 実VoiceOver検証は未確認のまま残し、合成評価だけで到達可能と断定しない。

## 2026-08-17: 中断時はコピー可能な現在地メモを使う

- 悩み: 静的ページのチェック状態は保存されず、実MCP・Hook状態とも自動同期しない。

- 根拠: Round 2で、中断後に状態を再構成する負担が複数のペルソナから再報告された。
- 影響: 自動保存機能は増やさず、未確認を成功に変えない再開手段を提供する。
