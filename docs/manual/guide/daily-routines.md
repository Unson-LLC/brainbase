# 日次ルーティン

Brainbaseは、1回セットアップして終わりではありません。

日々の会話、予定、メール、タスクから、あとで使える文脈を少しずつ残します。

## ohayo

朝に、その日の予定と優先順位を確認するルーティンです。

目的は、予定を読むことではなく、今日の判断に必要な文脈を揃えることです。

確認するもの:

- 今日の予定
- 締切が近いタスク
- 返すべき連絡
- 前日から残っている判断
- 今日進めるプロジェクト

## oyasumi

夜に、その日の会話や作業からPersonal KGへ残すべき情報を整理するルーティンです。

目的は、1日の出来事を日記として保存することではありません。次回AIが迷わないように、判断基準や関係性の変化を残すことです。

確認するもの:

- 新しく分かった関係者の前提
- 今後も使う判断基準
- プロジェクトの重要な変化
- 次回説明し直したくない背景

## retro

週に1回、蓄積した情報を見直すルーティンです。

目的は、Personal KGに置いた情報を見直し、SSOTへ入れるものと捨てるものを分けることです。

確認するもの:

- 今週よく出てきた判断基準
- プロジェクトごとの進展
- 関係者の変化
- 正本に昇格すべき決定事項
- まだ正本に入れず、様子を見るべき情報

## 最初は自動化しすぎない

ルーティンは便利ですが、最初から完全自動にしない方が安全です。

最初は、AIが見直し用の材料を出し、人間が確認してから正本に入れる形にします。運用が安定してから、通知や定期実行を広げます。
