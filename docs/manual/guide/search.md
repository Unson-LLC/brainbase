# 情報の関係を、回答に生かす

**意味や名前から見つけ、関係をたどり、根拠を確かめる。**

Brainbaseは、人物・プロジェクト・判断を、それぞれの関係とともに記録します。AIは質問に関係する候補を見つけ、必要な関係をたどり、記録された理由や根拠を確認して回答を組み立てます。

例えば「Atlasの仕事で、何を基準に判断する？」という質問では、次のように探せます。

```text
質問から対象のプロジェクトを特定する
                  ↓
そのプロジェクトに適用される判断をたどる
                  ↓
判断の内容と、記録された理由を読む
                  ↓
質問に答える根拠がそろったかをAIが確かめる
```

名前が似ているだけでは、別の案件の方針を適用できません。「どの判断がどの仕事に適用されるか」という関係を記録しておくことで、その関係を後の質問でも使えます。情報をグラフとして管理する意味は、**記録した判断を、必要な文脈とともに再利用できること**です。

## AIとGraphの役割

| 役割 | 担当すること |
| --- | --- |
| AI | 質問を解釈し、対象やたどる関係を選び、取得した根拠で回答できるか判断する |
| Graph | 記録された対象と関係を、有効時点・プロジェクト範囲に従って返す |
| 埋め込みモデル（任意） | 表現が違っても意味が近い候補を探すため、文章をベクトルに変換する |

Graphは記録されていない関係を補いません。検索順位が高いことも、回答が正しいことの証明にはなりません。根拠が足りない場合は、不足したまま伝えます。

## 外部APIは必須ではない

外部APIを設定しなくても、名前やIDから対象を見つけ、Graphの関係をたどれます。埋め込み未設定の候補検索は文字一致であり、意味検索とは区別して返します。言い換えで見つからない場合は、AIが名前や別名を確認して対象IDを選びます。

意味検索を追加したい場合は、埋め込みの生成先を選びます。

| 設定 | 候補の発見 | データの送信 |
| --- | --- | --- |
| 未設定 | 名前・別名・文字一致、AIが選んだID | 埋め込みのための通信なし |
| ローカルサービス | ベクトルによる意味検索 | 設定したローカルサービスへ送信 |
| 外部API | ベクトルによる意味検索 | 設定した外部サービスへ送信 |

ローカルモデルは同梱していません。利用者が用意したOpenAI互換の埋め込みサービスを接続できます。どの方式でも、関係探索と根拠確認の流れは同じです。APIが失敗した場合に、黙って別の方式へ切り替えることはありません。

## 提供状態

**開発中（npm未公開）**：このページの探索計画と任意の埋め込み接続は、開発版に追加する機能です。npm公開版への反映はリリース履歴で確認してください。既存のGraph v1は、正規の関係を探索する前にGraph v2への移行が必要です。

組織で使う場合は、共有データの保存先や権限の仕組みが加わります。ここで説明するOSS版は、所有者のローカルGraphを対象とし、組織のホストやデータを必要としません。
