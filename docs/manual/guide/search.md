# 情報の関係を、回答に生かす

**意味や名前から見つけ、関係をたどり、根拠を確かめる。**

Brainbaseは、人物・プロジェクト・判断を、それぞれの関係とともに記録します。AIは質問に関係する候補を見つけ、必要な関係をたどり、記録された理由や根拠を確認して回答を組み立てます。

例えば「Atlasの仕事で、何を基準に判断する？」という質問では、次のように探せます。

```text
質問から対象のプロジェクトを特定する
                  ↓
そのプロジェクトに適用される判断をたどる
                  ↓
判断の内容と、記録された理由を読む
                  ↓
質問に答える根拠がそろったかをAIが確かめる
```

名前が似ているだけでは、別の案件の方針を適用できません。「どの判断がどの仕事に適用されるか」という関係を記録しておくことで、その関係を後の質問でも使えます。情報をグラフとして管理する意味は、**記録した判断を、必要な文脈とともに再利用できること**です。

## AIとGraphの役割

| 役割 | 担当すること |
| --- | --- |
| AI | 質問を解釈し、対象やたどる関係を選び、取得した根拠で回答できるか判断する |
| Graph | 記録された対象と関係を、有効時点・プロジェクト範囲に従って返す |
| 埋め込みモデル（任意） | 表現が違っても意味が近い候補を探すため、文章をベクトルに変換する |

Graphは記録されていない関係を補いません。検索順位が高いことも、回答が正しいことの証明にはなりません。根拠が足りない場合は、不足したまま伝えます。

## 外部APIは必須ではない

外部APIを設定しなくても、名前やIDから対象を見つけ、Graphの関係をたどれます。埋め込み未設定の候補検索は文字一致であり、意味検索とは区別して返します。言い換えで見つからない場合は、AIが名前や別名を確認して対象IDを選びます。

意味検索を追加したい場合は、埋め込みの生成先を選びます。

| 設定 | 候補の発見 | データの送信 |
| --- | --- | --- |
| 未設定 | 名前・別名・文字一致、AIが選んだID | 埋め込みのための通信なし |
| ローカルサービス | ベクトルによる意味検索 | 設定したローカルサービスへ送信 |
| 外部API | ベクトルによる意味検索 | 設定した外部サービスへ送信 |

ローカルモデルは同梱していません。利用者が用意したOpenAI互換の埋め込みサービスを接続できます。どの方式でも、関係探索と根拠確認の流れは同じです。APIが失敗した場合に、黙って別の方式へ切り替えることはありません。

## OSSから組織環境へ移る

開発版では、OSSで使っていたGraphと判断根拠を組織サーバーへ持ち込めます。組織側でも同じ検索コアを使い、ID・関係・有効期間・根拠を保持します。接続設定がなければ、これまでどおり端末だけで使えます。

移送先は組織内の**所有者専用領域**です。組織全員に共有する操作ではありません。個人KGと元ファイルは端末に残り、移送後にもローカル利用を継続できます。

組織管理者が対応APIと保存先を反映した後、次の4項目を移行CLIの環境変数に設定します。

| 環境変数 | 内容 |
| --- | --- |
| `BRAINBASE_ORGANIZATION_URL` | 組織サービスのHTTPS URL |
| `BRAINBASE_ORGANIZATION_TOKEN` | 組織・所有者・対象プロジェクトを認可するBearerトークン |
| `BRAINBASE_ORGANIZATION_PROJECT` | 認可されたプロジェクトコード |
| `BRAINBASE_ORGANIZATION_GRAPH_ID` | 新しい保存スナップショットのID |

```bash
brainbase graph:upgrade --dir /path/to/personal-os
```

保存後にGraph全体を読み戻して照合し、`readbackVerified: true` を返します。元ファイルと接続設定は書き換えません。成功後、MCPプロセスにも同じ4項目を設定すると、同じ `search` ツールが組織側のGraphを検索します。設定不足や通信・認証失敗はエラーとなります。

同じID・同じ内容の再送は可能です。異なる内容は上書きせず拒否するため、更新したGraphを持ち込む際は新しいスナップショットIDを使います。常時同期の機能ではありません。

意味検索を使う場合、埋め込み生成先は組織サーバー側で設定します。端末側の設定は自動転送しません。生成先が未設定なら、意味検索の不足を明示します。返却される `authority` は、ローカルでは `local_graph`、組織側では `organization_graph` です。

対象はGraphと検索の移行互換です。組織共有Graphへの昇格や、製品全機能の完全上位互換を保証するものではありません。
