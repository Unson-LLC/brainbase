# Brainbaseとは

Brainbaseは、AIが仕事を始める前に必要な文脈を置いておくための基盤です。

CodexやClaude Codeは、コードやファイルを読むことは得意です。一方で、次のような文脈は毎回説明し直さないと抜け落ちます。

- この人は誰か
- この会社とはどんな関係か
- このプロジェクトは何を目指しているか
- どの判断基準を優先するか
- どの情報はまだ確認待ちで、どの情報は正本か

Brainbase MCPは、この文脈をAIから呼び出せる形にします。

## まず覚える用語

### SSOT

SSOTは Single Source of Truth の略です。Brainbaseでは「正本」と呼びます。

正本は、AIと人間が同じ前提として扱う情報です。人物、組織、プロジェクト、関係性、決定事項などは、会話ログやメモではなく正本を見に行くことを優先します。

### Personal KG

Personal KGは、個人の判断や経験を一時的に置く場所です。

たとえば、会話の中で得た気づき、判断基準、あとで正本に昇格したい情報を置きます。ここに入った情報は、ただちに仕事の正本になるわけではありません。

### 確認してから正本にする情報

メール、カレンダー、議事録、メモ、音声要約などから見つかった情報は、すぐに正本へ入れません。

まず確認待ちの情報として扱い、ユーザーが「これは今後も使う前提にしてよい」と承認したものだけをSSOTに入れます。承認なしに自動で正本を書き換えないことがBrainbaseの基本です。

## Brainbaseが提供する価値

Brainbaseの価値は、AIに長い説明を投げることではありません。

価値は、AIが作業のたびに次の問いを自分で確認できることです。

- この依頼はどのプロジェクトに属するか
- 関係者は誰か
- 過去にどんな判断があったか
- ユーザーはどんな基準で選ぶ傾向があるか
- まだ正本化してはいけない情報は何か

この状態になると、AIとの会話は「ゼロから説明する」ではなく「文脈を持った相手に依頼する」に近づきます。
