## 価値設計の順序

1. **WHO**: 平均像ではなく、実在する顧客と利用状況を選ぶ。
2. **便益**: その顧客にどんな望ましい変化が起きるかを言語化する。
3. **独自性**: 他の選択肢では得にくい理由を特定する。
4. **自分ごと化**: 顧客が便益と独自性を自分の状況へ結びつけられるか確かめる。
5. **WHAT**: WHOとの組み合わせに合わせて商品・体験・伝え方を調整する。
6. **検証**: 行動、継続、紹介、単価などで価値仮説を更新する。

## 成長段階ごとの問い

- **0→1**: 最初に強く価値を感じる少数顧客は誰か。
- **1→100**: 投資を拡大する前に、価値の再現性と収益性を確認できたか。
- **100→1000**: WHO×WHATの組み合わせを増やしても、便益と独自性が薄まらないか。
- **継続**: 新規獲得だけでなく、再評価、記憶、継続購買を観測しているか。

## 施策選択チェック

- SNS、広告、CRMなどの手段を先に選んでいないか。
- 顧客の発言だけでなく、行動が生じた状況と心理を確認したか。
- 世代・属性ラベルで価値観を代用していないか。
- 売上を顧客数、単価、頻度へ分け、どこを変える施策か明確か。
- ブランド表現の前に、再評価される便益と独自性が存在するか。

## Brainbaseでの適用

施策提案にはWHO、便益、独自性、観測事実、仮説、検証指標を添える。流行している手法は根拠にせず、顧客と価値からチャネルを選ぶ。
