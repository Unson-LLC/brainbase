# カルトマーケティング — 影響力の安全設計

**本質**: 熱狂を生む仕組みを成長テクニックとして無批判に転用せず、所属、物語、儀式、共通言語、紹介などの効用と、孤立、恐怖、搾取、服従を生む危険を分離する。

## 安全な利用と禁止境界

| 要素 | 安全な利用 | 禁止・要レビュー |
|---|---|---|
| ビジョン | 選択可能な共通目的 | 救済の独占、絶対的真理の主張 |
| 仲間意識 | 多様性と外部交流を保つ | 共通敵、外部遮断、批判者への攻撃 |
| 物語・象徴 | 意味や文化を共有 | 恐怖、不安、陰謀で依存させる |
| 儀式・イベント | 任意参加で関係を育てる | 高揚状態で契約・献金・労働を迫る |
| 共通言語 | 協働を速くする | ジャーゴンで外部検証を封じる |
| 紹介 | 十分な説明と自由意思 | 人間関係を利用した勧誘圧力 |
| 会員階層 | 責任と権限を透明化 | 課金・忠誠・無償労働で身分化 |

## リリース前チェック

- 退出、返金、批判、外部相談が実質的に可能か。
- 緊急性、恐怖、恥、仲間外れを意思決定圧力に使っていないか。
- 価格、便益、リスク、運営者、紹介報酬が明示されているか。
- コミュニティの善意を無償労働や販売ノルマへ転換していないか。
- 未成年、困窮者、病気や孤独を抱える人の脆弱性を利用していないか。
- 異論がブランドへの裏切りとして処理されていないか。

一つでも重大な懸念があれば、成長指標より安全を優先して停止し、法務・倫理レビューへ送る。
