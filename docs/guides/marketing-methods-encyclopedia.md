## 選択の順番

1. 売上・利益上の問題を一文にする。
2. WHO、WHAT、HOWのどこが未確定かを分ける。
3. R（調査）→STP→MM（施策構成）→I（実行）→C（管理）の詰まりを特定する。
4. 手法を一つ選び、適用条件・費用・主要指標・中止条件を置く。
5. 結果をControlへ戻し、WHO・WHAT・HOWを更新する。

## よくある誤り

- SNS、AI、データドリブンなど流行語から施策を選ぶ。
- HOWだけを最適化し、WHOとWHATの不一致を広告量で埋める。
- 手法ごとに別のKPIを置き、売上・利益への接続を失う。
- 網羅表を実行リストとして扱う。手法の多さは優先順位ではない。
- AIの整理結果を原典・顧客・実績で検証せず採用する。

## Brainbaseでの回答契約

マーケティング相談には、`事業課題 / WHO / WHAT / HOW / 詰まっている工程 / 採用手法 / 適用条件 / 指標 / 中止条件`を返す。手法名だけを推薦せず、判断のつながりを残す。
