## EOSの6モジュール

| モジュール | 実装するもの |
|---|---|
| Vision | コアバリュー、存在理由、長期目標、3年像、1年計画、四半期優先事項 |
| People | 正しい人を正しい席へ置くアカウンタビリティ設計 |
| Data | 結果を先読みできる少数の週次スコアカード |
| Issues | 課題を隠さず、特定・議論・解決するIDS |
| Process | 主要プロセスを80/20で簡潔に標準化する |
| Traction | 90日のRocksと週次会議で実行規律を作る |

## 運用の最小単位

1. 経営チームでビジョン・トラクション・シートを作る。
2. 四半期に3〜7個の最優先事項を置き、一項目一責任者にする。
3. 週次スコアカードで先行指標の異常を検知する。
4. 課題を人のせいにせずIDSで根本原因まで解く。
5. 毎週同じアジェンダで進捗・To Do・課題を確認する。
6. 四半期ごとに優先事項と組織の健全性を更新する。
