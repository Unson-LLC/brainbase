# 調査依頼・証拠管理ガードレール

**本質**: 調査の成否を「対象者から情報を得られたか」だけで測らず、依頼目的の適法性、手段の相当性、事実と推測の分離、秘密保持、依頼者と対象者の安全まで含めて管理する。

> 原本には盗聴、潜入、追跡、対人工作等の記述があるが、本ガイドはそれらを実行手順として採用しない。探偵業の届出や契約、個別案件の適法性を判断する法律文書でもない。実施前に最新法令と所管官庁の案内を確認し、必要に応じて弁護士・警察等へ相談する。

## 先に置く法令上の境界

警察庁の現行案内では、探偵業務を行っても他法令で禁止・制限された行為が許されるわけではなく、生活の平穏や個人の権利利益を侵害しないことが実施原則とされている。また、契約前後の書面、違法目的への利用禁止、秘密保持、取得資料の不正・不当利用防止が求められる。

- [警察庁「探偵業について」](https://www.npa.go.jp/bureau/safetylife/tanteigyou/index.html)
- [警察庁「探偵業法の解釈運用基準」](https://www.npa.go.jp/laws/notification/seian/seiki/20240401seianki168.pdf)
- [個人情報保護委員会「個人情報保護法等」](https://www.ppc.go.jp/personalinfo/)

## 依頼受理のゲート

次のいずれかが不明なら、調査へ進まず専門家確認または受理拒否とする。

1. 依頼者の本人性と、対象との関係を確認できるか。
2. 目的、利用先、共有先を具体的に説明できるか。
3. 犯罪、差別、報復、脅迫、ストーカー、DV、保護命令違反へ使われないか。
4. 取得しようとする情報が目的に対して必要最小限か。
5. 手段ごとの適法性、安全性、第三者への影響を確認したか。
6. 中止条件、費用上限、報告範囲、保管・削除期限を合意したか。

## 調査設計

```text
依頼者の主張
  → 検証可能な問い
  → 必要最小限の情報
  → 許容される取得方法
  → 時刻・出典付き観察記録
  → 複数証拠による照合
  → 事実／推測／未確認を分けた報告
```

- 最初の仮説に合う情報だけを集めず、反証条件を先に決める。
- 「確認できなかった」を「存在しない」や「潔白」と言い換えない。
- 伝聞、公開情報、現場観察、依頼者提供資料を出典別に管理する。
- 原本を保全し、作業コピー、時刻、取得者、加工履歴を記録する。
- 人身危険、対立激化、違法性の疑いが生じたら中止・エスカレーションする。

## 報告の品質

| 区分 | 記述例 |
|---|---|
| 観察事実 | いつ、どこで、何を、どの出典で確認したか |
| 解釈 | 事実から考えられる説明と、その根拠 |
| 代替仮説 | 同じ事実を説明し得る別の可能性 |
| 未確認 | 取得できなかった情報、範囲、理由 |
| 制約 | 調査期間、視認性、情報の鮮度、法的・技術的限界 |

依頼者が期待した結論と一致しなくても、証拠にない断定を加えない。感情的な状況では、結果の伝達と次の意思決定支援を分け、医療・法務・警察等の専門領域を代替しない。

## 情報管理

- 案件ごとにアクセス権を分け、知る必要のない者へ共有しない。
- 個人情報、位置、写真、音声、連絡先を通常文書より強く保護する。
- 外部委託の可否、委託先の資格、秘密保持、再委託を確認する。
- 送付先と本人性を確認し、安全な方法で報告する。
- 契約と法令に従い、保持期限後は復元可能性も含めて削除する。
- 漏えい、誤送信、端末紛失を想定した連絡・封じ込め手順を持つ。

## Brainbaseでの適用

Graphには案件の存在、責任者、承認・中止判断、保持期限等の必要最小限のメタ情報だけを置く。対象者の行動履歴やセンシティブな証拠本文はGraphや一般チーム文書へ展開せず、権限管理された案件正本で扱う。本ガイドは一般ガードレールであり、個別案件の調査権限や適法性を与えるものではない。
