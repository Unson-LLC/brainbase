## 学習マップ

```text
目的・環境・安全制約
  → 機構・電子・組込み設計
  → PythonとROSによる構成・通信
  → 座標・変換・確率などの数学基礎
  → センサー知覚とアクチュエータ
  → 状態推定・制御・動作計画
  → 移動・マニピュレーション
  → 人間ロボット相互作用と倫理
  → シミュレーション、実機試験、配備
```

## 設計レビューの問い

- タスク、環境、利用者、安全境界を先に定義したか。
- センサーの観測限界と、推定の不確実性をモデル化したか。
- 座標系、単位、時間同期、通信インターフェースが一貫しているか。
- 制御周期、遅延、飽和、非常停止を考慮したか。
- シミュレーションと実機の差を測るテストがあるか。
- 人間の予測可能性、説明可能性、プライバシー、責任分界を検討したか。
- 実験結果と配備可能性を混同していないか。

## Python・ROS実習の進め方

1. 小さなノードと明示的なメッセージ契約から始める。
2. センサー入力、状態推定、意思決定、制御出力を分離する。
3. 記録・再生可能なデータでアルゴリズムを比較する。
4. 単体、シミュレーション、Hardware-in-the-loop、制限環境の実機試験を段階化する。
5. 各段階に成功条件、停止条件、ログ、再現手順を置く。
