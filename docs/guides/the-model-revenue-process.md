## 設計手順

1. 顧客の認知から継続・拡張までをステージ化する。
2. 各ステージの入口、出口、担当、滞留期限、失注・保留理由を定義する。
3. 部門間の受け渡し条件と、未成熟リードを戻すリサイクル経路を決める。
4. 件数だけでなく転換率、滞留時間、処理能力を時系列で追う。
5. 売上を各段階の母数と転換率へ分解し、最大のボトルネックから改善する。
6. 受注後の活用・継続・拡張を同じプロセスへつなぐ。

## 運用チェック

- 部門ごとの目標達成が、下流の不良案件や解約を増やしていないか。
- 引き渡しの定義が、担当者の感覚ではなく観測可能な条件になっているか。
- 失注・保留案件が放置されず、理由別の再接触ルールを持つか。
- ボトルネックが需要、処理能力、転換率、継続のどこかを区別したか。
- 数字のスナップショットだけでなく、コホートと推移を見ているか。
