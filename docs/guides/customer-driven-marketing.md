**本質**: 集計値だけで平均的な架空顧客を作らず、顧客構造を定量で捉えたうえで、実在する一人の行動と心理を深掘りし、得たアイデアを再び定量で検証する。

## 改善ループ

```text
顧客ピラミッドで構造を把握
  → 調べるセグメントと実在顧客を選ぶ
  → 認知・初回利用・継続・離反の事実を時系列で聞く
  → 行動が変わった「きっかけ」と便益を特定
  → プロダクト／コミュニケーションのアイデアへ変換
  → コンセプトテストや実験で母集団への再現性を検証
  → セグメント移動を追跡し、次のN1を選ぶ
```

## インタビュー原則

- 意見や要望より、実際に起きた行動、直前の状況、比較対象、決定理由を聞く。
- 認知から現在までを時系列で描き、こちらの仮説で空白を埋めない。
- ロイヤル顧客だけでなく、一般、離反、認知未購入、未認知も目的に応じて選ぶ。
- 一人の特徴と、他の顧客にも再現しそうな便益・きっかけを分けて記録する。

## 判定基準

N1から具体的な仮説が生まれたことは発見であって、再現性の証明ではない。対象母数、比較条件、行動指標を置いて検証し、セグメント間の移動が改善した場合にのみ投資を拡大する。
