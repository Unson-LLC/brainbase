# 0.50.15（npm公開前）

この版はnpm公開前の候補です。公開状態と利用ホストへの配備は別途確認します。

0.50.14で世界の区画を輪の配置に替えたとき、`ui/world/world-placement.js` から外した2つの書き出し名（`districtStreetLots`・`districtGroundPlan`）を、0.50.8と同じ中身で戻します（#1002）。利用ホストの配備前検査は、配信する `/oss` のmoduleから書き出し名が減ると落とします。配備前に開いたタブが、新しいファイルに古い名前を求めることがあるためです。

この2つはこのpackageの中では呼びません。世界タブの見た目と動き、公開API、MCPツール、認証・権限の契約は変更しません。0.50.14に含まれる変更を保持します。
