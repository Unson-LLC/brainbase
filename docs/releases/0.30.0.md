# 0.30.0

## 変更

Personal Webのナビの「今日」を「判断の履歴」に改めます（前提台帳U1、2026-10-11採用）。中身は判断の見返しで、組織版の「判断の履歴」と同じ名前と画面ID（`value-proofs`）にそろえます。古いリンク `#today` と `#today?decision=<id>` は、判断の履歴の同じ判断へ転送します。

## 追加

世界の部品（`ui/world/world-view.js`）に、判断を開くリンクの行き先を差し替える `judgmentHref` を追加します。既定は `#value-proofs?decision=<id>` です。組織版は、この指定で自分の画面の判断の履歴へつなげます。
