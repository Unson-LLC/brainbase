# 0.50.19（npm公開前）

この版はnpm公開前の候補です。公開状態と利用ホストへの配備は別途確認します。

hosted MCP で Claude Code の判断hookを受け取るHTTPの受け口を、公開subpath `remote-judgment-hook-http` として加えます（#990）。ホストが認証を確かめたあとに `handleRemoteJudgmentHookRequest` を呼ぶと、本文の大きさ・必須項目・プロジェクトの範囲を確かめ、正本の判断dispatcherへ渡します。認証の種類から許可を決める `remoteJudgmentHookHostFlags` も含みます。共有bearerや会社権限の認証では、remote の Claude Code 宣言を受け付けません。失敗したときは成功扱いにせず、理由のコードを返します。

公開subpath `judgment-journal-turn-publisher` も加えます。person JWT で受け付けた hosted Claude Code の Stop のあと、書き終わった判断のjournalを読み、組織APIへ1回分のやりとりとして送ります。送れなかったときもhookの応答は変えず、安全な理由のコードだけを知らせます。

試し方は `docs/runbooks/hosted-claude-code-judgment-hook-trial.md` にあります。このpackageはHTTPの受け口だけを渡し、Claude Code のhookスクリプトは入れません。本番への配備はこの版に含みません。

既存の公開API、MCPツール、認証・権限の契約は変更しません。0.50.18に含まれる変更を保持します。
