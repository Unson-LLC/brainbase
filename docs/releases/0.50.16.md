# 0.50.16（npm公開前）

議事録UIに `pagePresentation: 'table'` を追加します。共通のヘッダー、見方タブ、条件チップ、選択小窓、札の行、右詳細を使い、会議日時・確認状態・プロジェクト・参加者・版を一覧にします。省略時の表示は維持します。

一覧summaryに、取り下げていない各議事録の現行版の確認状態だけを加えます。既存snapshotと閲覧許可の結果を使い、取得・認可経路や呼出数は変更しません。本文・外部参照・確認者の情報は一覧へ加えません。

本文は既存の保存処理で新しい版になり、前の版を保持します。未保存時の確認、保存中の入力保護、読み返し失敗時の本文保持を追加します。会議名・日時・参加者・プロジェクトの後編集は追加しません。確認・取り下げ・外部参照・関連情報・失敗と再試行は維持します。

共通drawer/input frameは `beforeClose`、form rowは `appearance: 'quiet'`、topbarは `wrap: true` を明示選択できます。配色の値は変更しません。npm公開と利用ホストへの配備は別途確認します。
