# 0.24.1

判断で予測に使った世界モデルへ、観測した結果を書き戻す部品を、既存の出口 `@unson/brainbase-mcp/judgment-frame` に追加します（ADR-014 F6、`story-judgment-model-outcome-feedback`）。

`brainbase_judgment_model_outcome_record` は、結果が支持・反証・判定不能のどれかを、予測・観測・成り立つ条件・証拠とともに記録します。反証には、測定誤差・実行差・外部変化の三つを退けた理由が必要で、予測との差だけでは反証になりません。世界モデル本体の版・検証状態・採用状態は変えません。保存先・記録者・認可は取り込む側が持ちます。

結果の読込みを渡したhostでは、判断の枠組みの一覧に、世界モデルの今の版への支持・反証・判定不能の件数と反証の条件が表示されます。採用案が反証のある世界モデルで予測するときは、`chosen_uses_refuted_model` で人間へ戻します（F5）。一覧のdigestは定義だけから作るので、本文取得とhostのdigest照合は変わりません。読込みを渡さないhostの動作は従来どおりです。

組織版での保存先と経路、brainbase-unsonでの配線、本番の表の適用は別の段階です。
