# 0.28.0

知識を探す正本（Graph・所有repo・チームのDrive・個人KG・作業場）を、内容の種類（`content_type`）と相手（`audience`）から決める部品を、新しい出口 `@unson/brainbase-mcp/knowledge-resolution-service` として追加します（`story-knowledge-resolution-service-exit-v1`）。brainbase-unsonの部品を処理を変えずに移したもので、受領書は探す場所を示すだけで、検索したことや不在を示しません。

外部のサービスを呼ばないので、OSSの既定の動作は変わりません。

組織版への会社権限の部品（`authority-knowledge-resolution-service`）の移設と、brainbase-unsonでの取り込みは別の段階です。
