# 0.41.0

## 保存競合からの復旧

知識の下書きを保存するときに競合した場合、入力中の原文・出典・提案を保持して、同じ下書きの最新版を確認できます。最新版の版を確認できた後、利用者が「保持した内容を再適用して保存」を選べます。取得に失敗した場合は、保持した内容と再試行の案内を表示します。

## 目的と関係者の確認状態

目的の読取結果に、正本の出典・版・digest・確認時刻を含む `brainbase.objective-readback.v1` を追加します。不完全な定義や参照先が一致しない結果を拒否し、画面では確認済み・取得失敗・確認できない状態を区別します。

プロジェクトの関係者は、取得済み・部分取得・取得不可・未確認・確認済みの空を区別します。部分取得や再試行時も、確認できた関係者を画面に残します。

## 読取に失敗したときの案内

Graphと判断履歴は、取得失敗の説明と再読み込みを表示します。議事録一覧は再試行後に一覧へフォーカスを戻し、世界の画面は確認できる内容と次の行動を示します。
