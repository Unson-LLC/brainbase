# 0.34.0

## 追加

Graphのオントロジーを新しい公開subpathとして出します。

- `@unson/brainbase-mcp/ontology-kernel`：型と関係の定義の検査、決定の推論、影響の見積もり、版の候補の組み立て（`OntologyKernel`・`OntologyError`・`buildOntologyReleaseCandidate`）
- `@unson/brainbase-mcp/ontology-registry`：設定フォルダの版の一覧と各版のマニフェストを読み、署名つき公開の受領証を検証してから版を解決する（`OntologyRegistry`）
- `@unson/brainbase-mcp/ontology-publication`：正規JSON・SHA-256・公開の受領証の検証
- `@unson/brainbase-mcp/ontology-release-trust`：受領証の結びつきの検査と信頼する公開鍵の読み込み

brainbase-unsonの実装と同じ振る舞いです。版の登録簿は渡された `rootDir`・`configDir`（既定 `config/ontology`）から読み、組織固有の値は持ちません。
