# 0.50.13（npm公開前）

この版はnpm公開前の候補です。公開状態と利用ホストへの配備は別途確認します。

判断の枠組み（哲学・目的・世界モデル）の証拠判定を、公開subpath `@unson/brainbase-mcp/judgment-frame-evidence` として加えます。組織版のHostにあった判定を移したもので、一覧・本文・記録の証拠の正規化と、1つの依頼の完結判定を持ちます。

`hasCompleteJudgmentFrame` は、同じ会話で読んだ一覧のdigest（`sessionCatalogDigests`）を受け取ります。その依頼で一覧を読んでいなくても、本文の取得と記録が同じdigestで成功していれば完結と判定します。本文の取得と記録はサーバーが古いdigestを拒否するため、成功は一覧が変わっていないことを示します。

0.50.12に含まれる変更を保持します。既存のHost、MCPツール、認証・権限・保存後のreadbackの契約は変更しません。この版だけでは、Hostの動きは変わりません。
