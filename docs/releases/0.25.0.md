# 0.25.0

同じPlaudやTactiqを複数のアカウントでつないでも、資格情報・読んだ位置・全文待ち・失敗・受け渡しが接続ごとに分かれる同期の部品を、新しい出口 `@unson/brainbase-mcp/meeting-source-connection` として追加します（`story-meeting-source-connection-sync-v1`）。

接続IDはBrainbaseが発行し、外部の接続基盤のIDは参照としてだけ持ちます。接続の確認は一覧と全文の1ページ目を実際に読み、一覧が読めたときだけ接続済みに、全文が読めたときだけ全文の読み取りを能力に入れます。同期は全文待ちの会議を保留に残し、取得の失敗を「新しい会議が無い」と記録しません。同じ全文は二度渡さず、変わったときだけ新しい版として渡します。止まっていた期間を指定して取り直しても重複しません。MCPのOAuth（探索・動的なクライアント登録・PKCE・token交換）は、組織接続の共通部品 `@unson/brainbase-mcp/organization-connection` に差し込んで使います。資格情報・同期の状態・受け渡し先は差し込み口で、tokenは読み戻し・状態・エラーに出しません。

本物のPlaud・Tactiqでの接続の実測、組織版での接続の記録・画面・定期実行、Manaの受付への受け渡しは別の段階です。
