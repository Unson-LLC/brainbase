# 0.26.1

判断の枠組みの記録で、世界モデルの予測にデータでの確認を持たせます（ADR-014、`story-judgment-prediction-check`）。

`brainbase_judgment_frame_record` の予測のuseは、任意の `check`（何が観測されたら外れか、held・failed・uncheckedの状態、どこで確かめたか）を持てます。採用案が確かめて外れた予測に頼るときは `chosen_relies_on_failed_prediction` を返し、hostが人間へ戻します。記録の応答は、採用案の予測の確認件数 `prediction_checks` を返します。記録の版は変えず、`check` を使わない記録は従来どおりです。

useに未知の欄があると記録を不成功にする既存のhostでは、この版を取り込む前にhost側で `check` を受け付ける必要があります。
