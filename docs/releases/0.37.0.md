# 0.37.0

## 追加

`CanonicalTaskService.updateTask` に任意入力 `source_refs_append` を追加します（`story-canonical-task-source-refs-append`）。今ある `source_refs` を保持したまま、plain JSON objectの参照を後ろに追加します。既存の参照の順序と既存の重複はそのまま残します。

Unicodeを含むobjectキーの順序だけが違う同じ参照は、追加を重複させません。同じ操作をキーの順序を変えて再送しても版は増えず、同じ更新結果を返します。置換の `source_refs` と同時に指定した場合と、不正な入力・古い版の指定は断り、保存済みのTaskは変えません。

既存の権限・範囲・期待する版・書き込み・監査の仕組みをそのまま使います。`source_refs` の置換と、追記を指定しない操作の既存の挙動は変わりません。
