# 0.32.0

## 追加

世界の部品（`ui/world/world-view.js`）に、記憶の循環の状態を受け取る `memoryStatus` を追加します（前提台帳P18、2026-10-11採用）。答えは `{ status, night?, candidates?, review_href? }` です。夜の整理が失敗した、または動かなかった夜は「整理できなかった夜」と目立たせます。本人が決める記憶の候補があれば件数と「候補の確認を開く」のリンクを出します。リンクは `https:` とこの画面の中のリンクだけを通します。

渡されなければ「記憶の整理：未接続」と出し、候補の件数を0件とは出しません。読めなかった部分も「読めない」と出します。Personal Webは夜の整理の結果を受け取る置き場が無いため、この表示になります。
