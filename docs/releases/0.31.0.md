# 0.31.0

## 追加

判断の解決で共有する部品の公開subpath `judgment-resolution-contract` を追加します。`JudgmentResolutionError`（`code`・`status`・`toJSON`）、`canonicalJson`（キーを符号位置の順に並べ、有限でない数や `undefined` を拒否する正規JSON）、`sha256Hex`、`computeRequestDigest` を含みます。brainbase-unsonの判断のサービスと同じ実装です。判断の解決の経路を組織版へ移すとき、経路とサービスが同じエラーの型を共有するために使います。

## 変更

判断Hook（`judgment-host`）の `canonicalJson` は、この出口の実装を読むようにまとめました。出力は変わりません。
