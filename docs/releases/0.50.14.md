# 0.50.14（npm公開前）

この版はnpm公開前の候補です。公開状態と利用ホストへの配備は別途確認します。

世界タブを、世界（全事業）→ 事業（区画）→ 仕事の集まり（通り）の3つの縮尺で見られるようにします（#998）。左下の「いまの動き」は、見ている縮尺ごとに中身が変わります。世界では事業ごとの進行中・待ちの件数、事業では通りごとの内訳とそこにいるAI、通りでは仕事1件ごとにどのAIがいて、動いているか・待っているか・終えたかを出します。表示はタスクの状態とホストが確かめた稼働の知らせからの計算だけで、世界は何も保存しません。

事業の区画は、庁舎と広場を中心に輪で外へ広がる形になります。仕事の集まりは円の扇1つを占め、広場に近い輪から外の輪へ建物が埋まります。件数が10倍になっても幅は3倍未満に収まります。

0.50.13に含まれる変更を保持します。世界タブ以外の公開API、MCPツール、認証・権限の契約は変更しません。
