# 0.50.17（npm公開前）

この版はnpm公開前の候補です。公開状態と利用ホストへの配備は別途確認します。

判断の履歴の絞り込み（検索・期間・プロジェクト・判断したAI）を、小窓に入れずに一覧の直上へ常に並べます（#963）。仕事ページと同じ並べ方です。開く操作がいらなくなり、いまどの条件で見ているかが一目で分かります。

件数行を「取得済み N件 · 条件一致 M件 · 表示 1–M件 · 総数 T件」の形にそろえます。全件数が分からないときは、総数を「未確認」と出します。0件と言い切れないときの文言は変えません。絞り込みの欄で入力中に画面が描き直されても、選んでいた欄から外れません。

プロジェクトと判断したAIの選択はnormalモードだけに出します。legacyモードは期間と検索の手元の集計のままです。ページ送り、再読み込み、右詳細は変えません。新しい色・書体・影・動きは足さず、既存のトークンを使います。

公開API、MCPツール、認証・権限の契約は変更しません。0.50.16に含まれる変更を保持します。
