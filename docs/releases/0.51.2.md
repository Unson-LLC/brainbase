# 0.51.2（npm公開前）

この版は npm 公開前の候補です。公開状態と利用ホストへの配備は別途確認します。

`0.51.1`（`main` / `1a653d52`）をベースに、`#1090`（`543991814`、Item #165）およびテスト専用の実行時間閾値安定化（`6580029ef`）のみを cherry-pick したパッチリリース候補です。他の `develop` コミットは含みません。

---

## Changes since `0.51.1`

- **Antigravity CLI judgment hook の複数 JSON MCP text block 分割復元（`#1090` / `543991814` / Item #165）**:
  - 複数 JSON ブロックが改行連結された MCP ツール応答を厳密な O(n) 走査で安全に分割する `splitConcatenatedJsonTextBlocks` を追加（全ブロックが有効な JSON の場合のみ分割、不正入力は fail-open で単一ブロックのまま維持）。
  - `isTruncatedToolResult` を更新し、全ブロックが有効な JSON として分割できる場合に JSON 文字列値内の `<truncated N bytes>` を誤って切り詰め判定しないよう修正。
  - `extractToolResultTextBlocksFromTranscript` および `handlePostToolUse` が `tool_response.content` を複数 text block として復元するよう更新し、Host 側契約（`compact_4block_v3` 等）との整合を確保。
- **テスト安定化（`6580029ef` / テスト専用・`src/` 差分なし）**:
  - `tests/antigravity-judgment-hook.test.ts` の 500k+ 文字線形時間回帰テストの経過時間上限を 200ms から 5,000ms へ引き上げ、共有 CI ランナー負荷時のフレーク耐性を確保しつつ O(n²) / ReDoS 回帰検知を維持。
