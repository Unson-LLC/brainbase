# 0.24.0

PlaudとTactiqの会議を、途中で切れない全文として読み出す部品を、新しい出口 `@unson/brainbase-mcp/meeting-source-reader` として追加します（`story-meeting-source-full-transcript-v1`）。MCPのツールを呼ぶ関数を外から受け取り、接続・認証・資格情報・保存先は持ちません。

全文は最後のページまで読めたときだけ全文として返します。途中までの全文、空の全文、要約を全文として扱いません。読めない会議は、認可切れ・プランや許可の不足・取得枠・時間切れ・生成待ち・途中停止を、接続全体か会議だけかと次に試す時刻とともに返します。Tactiqの全文の取得枠（1時間に異なる会議10件、読み直しは数えない）は呼ぶ前に数えます。全文の `digest` は brainbase-unson の `transcript_hash` と同じ値です。

実アカウントでの読み出しの記録、組織版での接続と同期、Manaの受付への受け渡しは別の段階です。
