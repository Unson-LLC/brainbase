## Changes since `0.51.4`

- **`knowledge-promotion` の `personal_share` + `decision` 決裁主体を承認者 `approverPersonId` へ統一（`#1105` / `8a6ae6b38` / URS-048 v4 / Item #220・#221）**:
  - `src/knowledge-promotion.ts`: `buildOrganizationKnowledgeEvent()` で `normalized.kind === 'decision'` の場合、`approval_kind` が `personal_share` でも `organization_candidate` でも `decision_authority.decider_id` を組織審査の承認者 `approverPersonId`（RACI 検証済み決裁者）へ統一。下流の `buildNormalizedGraphMutation`（`entity.payload.decision_authority`）および `reconcileGraphProjection`（`decision_owner_person_id`）も自動的に `approverPersonId` へ整合。
  - 申請者・所有者来歴（`request.owner_person_id`、`promotion_evidence` / `permission_snapshot` の `owner_consent_receipt_id`、`lineage.owner_person_id`）および `withdrawPersonalShares` / `withdrawPromotedEntity` による本人撤回権限は従来どおり `request.owner_person_id` に紐づけて維持。
  - `tests/knowledge-promotion.test.ts`: `personal_share` + `decision` 承認時の `decision_authority.decider_id`・Graph mutation・`reconcileGraphProjection` 整合および `owner_person_id` 来歴・本人撤回権限の回帰テストを追加・更新。
