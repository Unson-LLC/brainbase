# 0.50.11（npm公開前）

この版はnpm公開前の候補です。公開状態と利用ホストへの配備は別途確認します。

共通部品のdialog（`showDialog` と `showWorkspaceEditDialog`）の背景クリックを、`closedby="any"` でブラウザに任せます。未対応のブラウザでは、これまでの判定を機能検出つきの代替として残します。閉じたときの通知・フォーカスの戻り・内側のクリックの扱いは変えません。

`ui/` に古い書き方が入ると落ちるテストを足し、対応ブラウザの基準（Baselineの区分ごとの扱い）を共通UIの規約に書きました。スキャナーは開発用の依存で、公開するパッケージの中身には入りません。

0.50.10に含まれる変更を保持します。認証・権限・保存後のreadbackの契約は変更しません。
