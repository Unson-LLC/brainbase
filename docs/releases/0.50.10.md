# 0.50.10（npm公開前）

この版はnpm公開前の候補です。公開状態と利用ホストへの配備は別途確認します。

共通ヘッダーを52px・下線付きへそろえ、タブと右の道具を渡すslotを追加します。タブ付きページではH1を読み上げ用に保持し、タブなしではタイトルと検索を表示します。ヘッダーを使わない画面は変わりません。

見方タブ、コンパクト検索・単一/複数の候補選択、条件チップ、丸い選択肢、2列の操作小窓、右から開く入力枠、色帯付きの札行と並び替えの動きを共通部品へ追加します。新しい見た目は明示選択で使い、既存の公開API・既定の検索/候補/drawerの見た目を保持します。文言・データ・権限・保存処理は呼び出し元が渡します。

規約に役割、見た目、状態、動き、呼び出し方、禁止事項と今後の標準を記載します。既存ページの検索・プルダウンの置き換えは行いません。

追加変更のためpatch版です。公開はレビュー後のmainへのマージで起動するGitHub Actionsだけで行います。ホストは公開後に正規npmのexact pinを更新し、共通CSSを上書きせずに使います。
