# 0.26.0

世界の都市から、その事業で使う外の道具へ出られるようにします（`story-world-business-exits-v1`）。`createWorldView` に任意の `businessExits(business)` を渡すと、都市の詳細と3Dを出せないときの一覧に「この事業の道具」の欄を出し、canvasでは区画の門の外に道具ごとの駅を置きます。駅は状態を姿で表し（明かり＝使える、閉じた改札＝権限が必要、霧＝未確認・読めない）、選ぶと都市の詳細の該当行を選びます。`businessExits` を渡さないホストの表示は変わりません。

答えが読めないときは0件として扱わず理由を出し、件数の無い要対応は「件数は未確認」と出します。リンクは `https:` とホスト内の相対リンクだけを描き、それ以外は捨てた件数を出します。状態の言葉は語彙の `exit_states` で持ち主が与えられます。

GPUを使えずWebGLがソフトウェア描画になる環境では、場面の構築でページが長く止まるため、理由を添えて一覧で出します。

組織版での道具の台帳・権限・申請と、組織版の画面での表示確認は別の段階です。
