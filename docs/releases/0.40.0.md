# 0.40.0

## 追加

共通部品 `ui/people-and-companies-view` の「人を加える」で、その人が関わるプロジェクトを選べるようにします（`story-people-and-companies-person-project-v1`）。ホストが `GET /api/graph/people-and-companies` の結果に `personProjects`（`[{ code, name }]`）を入れたときだけ、「関わるプロジェクト」の選択欄を出します。選ばないと保存せず、選んだものを訂正の `entity.projectCode` で送ります。「会社を加える」には出しません。

`personProjects` の形が正しくなければ（`code` が空など）、読み取りを失敗として扱い、推測で選択肢を作りません。

`ui/graph-view-shared` の `openCreateEntity` は `projects` を受け取ります。人だけを作るフォームに限って使います。

## 互換

`personProjects` を返さないホスト（OSSの手元のホストを含む）では、画面も送る内容も今までどおりです。
