# 0.36.0

## 追加

議事録の部品（`@unson/brainbase-mcp/meeting-minutes`）の store に、議事録の文書を取り下げる `withdraw_minutes({ minutes_id, expected_revision, idempotency_key?, idempotency_fingerprint? }, context)` を追加します（`story-meeting-minutes-withdraw-v1`）。会議と文書の両方に書き込める人だけが実行でき、文書に `withdrawal: { actor_id, withdrawn_at }` を記録します。版と本文は消しません。

取り下げた文書は `list_meetings` の要約から外れ、`get_meeting` の詳細では履歴として読めます。取り下げた文書への新しい版の保存と確定は `invalid_input` で断ります。取り下げ済みへの再実行は最初の記録を保ち、冪等キーの再送は同じ結果を返します。
