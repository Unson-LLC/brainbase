## Changes since `0.51.5`

- **`dist/judgment-host.js` の外部依存ゼロ回復および隔離 tarball ロード互換修復（`#1107` / `e4fd852b0` / Item #266・#267）**:
  - `src/judgment-task-progress.ts`: `zod` へのランタイム依存を除去し、ゼロ外部依存の厳格バリデータ（`TaskProgressValidationError`・`taskProgressScopeSchema`・`taskProgressObservationSchema`）へ置き換え。トリミング・長さ上限（1〜512）・識別子検証・own / 継承列挙キーに対する厳格拒否（`unrecognized_keys`）およびクラスインスタンス受理で従来の Zod 4 `strict()` 互換を維持。
  - `tests/judgment-task-progress.test.ts`: `taskProgressScopeSchema`・`taskProgressObservationSchema` および `processJudgmentHook` 連携の境界値・厳格拒否（継承列挙キー・`undefined` 値・`__proto__` 等）回帰テストを追加。
  - `tests/judgment-host-zero-external-deps.test.ts`: `dist/judgment-host.js` から到達可能な静的モジュールグラフに `node:` 組み込み以外の外部依存が存在しないこと、および `node_modules` 非存在の隔離ディレクトリ／tarball 展開環境で `dist/judgment-host.js` を直接 import できることを検証する回帰テストを追加。
