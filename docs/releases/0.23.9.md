# 0.23.9

知識・判断の一覧に種類・範囲・有効状態を添え、選択した項目の本文・出典・適用範囲・変更履歴へ進む階層を整えます。モバイルでは選択中の詳細へ移動する導線を表示します。詳細や履歴の取得に失敗した場合は正本未確認として再試行を示し、取得できるまで版の変更や失効を実行できません。検索結果が空または利用できないときは、前の選択と詳細を残しません。

Worldで事業・仕事・判断などの記録を読めない場合は、取得できた件数を総数として扱わず「件数未確認、0件とは確認できない」と表示します。ホスト全体が利用できない理由は対象欄ごとに折りたたんで確認できます。

npm公開、組織版の依存更新、実ブラウザの表示確認、本番配備と正本の読戻しは別の段階です。この候補の時点では本番画面を検証済みとはしません。
