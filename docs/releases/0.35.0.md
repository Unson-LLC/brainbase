# 0.35.0

## 追加

世界の部品（`ui/world/world-view.js`）に、判断のほかの待ち行列を受け取る `waitingQueues` を追加します（前提台帳P17・D9、2026-10-12採用）。ホストが `{ status: 'available', queues: [{ id, label, count, href, link_label? }] }` を返す関数を渡すと、件数が1以上の行列ごとに「{label} {count}件」と降り口のリンクを「待っている」に出します。件数が0の行列は出さず、読めない行列は「読めない。0件とは確認できません」と出します。降り口は事業の出口と同じ判定（`https:` かホスト内）で、それ以外にはリンクを付けません。渡さなければ今までと同じ画面です。
