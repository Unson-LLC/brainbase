# 0.41.6（npm公開前）

この版はnpm公開前の候補です。公開状態と利用ホストへの配備は別途確認します。

判断の履歴の詳細を右パネルで表示し、検索条件を共通の詳細検索パネルへまとめます。再読み込みは更新アイコン、確認時刻はその左に小さく表示します。取得範囲の注意は右の通知で確認でき、一覧の括弧書きは省きます。

共通の右パネルは閉じると右へフェードし、閉じた後に呼び出した要素へ戻ります。読み込み通知も完了後に右へフェードして消えます。動きを減らす設定では即時に閉じます。目的と現状の重複する取得範囲注意を除き、失敗の理由・再試行と未取得状態は維持します。

認証・権限・保存先・正本データの契約は変更しません。
