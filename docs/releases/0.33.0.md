# 0.33.0

## 追加

世界の部品（`ui/world/world-view.js`）に、本人を待っている判断の短い一覧を追加します（前提台帳U2、2026-10-11採用）。待っている判断（人に戻され、回答も会話での前進も無いもの）を新しい順に最大3件、本来の質問と「「判断の履歴」で開く」のリンクつきで出します。リンクはホストが渡す `judgmentHref` で同じ判断へ降ります。3件を超える分は「ほかN件は「判断の履歴」で見られます」と数えて隠しません。

待っている判断が無ければ一覧を出しません。判断の記録を読めないときは一覧を出さず、待っている判断を0件とも出しません。

新しい公開subpathとして、Graphの保守エンジン `@unson/brainbase-mcp/graph-maintenance-engine`（変更計画の組み立て・適用・スナップショットの検査とハッシュ）と、記憶の記録を見てよい範囲の判定 `@unson/brainbase-mcp/memory-scope-policy` を追加します。brainbase-unsonの実装と同じ振る舞いです。
