# 0.51.0（npm公開前 / Breaking changes included）

この版は npm 公開前の候補です。公開状態と利用ホストへの配備は別途確認します。

`0.50.31`（`main` / `6b864deb`）に `develop`（`8271da54`）を統合する minor リリース候補です。`main` に先行出荷済みの `0.50.25`〜`0.50.31` の全機能・セキュリティ修正を保持しつつ、組織固有機能 3 件の OSS からの削除（`#1027`・`#1037`・`#1040`）、`judgment-event-outbox` の `candidate_id: null` 条件付き受理（RFC-002 PR-3b `#1084`）、および新規公開 subpath `@unson/brainbase-mcp/world-model-impact-index`（`#1044`）ほか `develop` の更新を含みます。

## Breaking changes & Migration notes

### 1. 予約（Resource Reservations）の OSS からの削除（`#1027` / `#1033`）

テナント・承認・容量管理を伴う予約機能は組織管理の責務であるため、OSS コアから削除しました。

| Kind | Removed public surface | Replacement in `brainbase-organization` |
|---|---|---|
| package export | `@unson/brainbase-mcp/resource-reservations`（`ResourceReservationService`, `createResourceReservationProblemSnapshotPort`, `ResourceReservationError` ほか型） | `packages/company-os/resource-reservations.js`（`Unson-LLC/brainbase-organization#1428`） |
| package export | `@unson/brainbase-mcp/resource-reservation-http`（`createResourceReservationHttpHandler`, `/api/resource-reservations` ルート） | `packages/company-os/resource-reservation-http.js`（`Unson-LLC/brainbase-organization#1428`） |
| function | `createResourceReservationExecutionPort`（旧 `@unson/brainbase-mcp/execution-authority`） | 組織層の予約サービスから `ExecutionReservationPort` を供給 |

#### 移行手順
1. `@unson/brainbase-mcp/resource-reservations` および `@unson/brainbase-mcp/resource-reservation-http` からの import を、`brainbase-organization` の `packages/company-os/resource-reservations.js` / `resource-reservation-http.js` へ切り替えてください。
2. 予約台帳の永続化には組織層の PostgreSQL ストアを利用してください。

---

### 2. メンバー招待（Organization Member Invite）の OSS からの削除（`#1037`）

テナント・役割・認可・メンバー付与・監査を伴う招待機能は組織管理の責務であるため、`develop`（`#977`）で追加されていた本体と HTTP 受け口を OSS から除外しました（`0.50.x` の `main` には未出荷）。

| Kind | Removed public surface | Replacement in `brainbase-organization` |
|---|---|---|
| package export | `@unson/brainbase-mcp/organization-member-invite`（`OrganizationMemberInviteService`, `OrganizationMemberInviteError`, `createInMemoryOrganizationMemberInviteRepository`, `createOrganizationMemberInviteId`, `normalizeOrganizationMemberInviteEmail` ほか port 型） | `@unson/brainbase-organization-server-parts/organization-member-invites/kernel`（`Unson-LLC/brainbase-organization#1473`） |
| package export | `@unson/brainbase-mcp/organization-member-invite-http`（`createOrganizationMemberInviteHttpHandler`, `ORGANIZATION_MEMBER_INVITE_HTTP_VERSION`, `/api/v1/organization-member-invites` ルート） | `@unson/brainbase-organization-server-parts/organization-member-invites/http`（`Unson-LLC/brainbase-organization#1473`） |

#### 移行手順
1. `OrganizationMemberInviteService` および HTTP ハンドラの import 先を `@unson/brainbase-organization-server-parts/organization-member-invites/kernel` と `/http` へ切り替えてください。
2. 挙動・エラーコード・保存レコード形式は変更ありません。

---

### 3. 実行の意図（Execution Authority）の OSS からの削除（`#1040`）

実行の意図はテナント・承認・権限・委任および予約 port を前提としており、予約の移設（`#1027`）後は OSS 単体で完結しないため、OSS コアから削除しました。

| Kind | Removed public surface | Replacement in `brainbase-organization` |
|---|---|---|
| package export | `@unson/brainbase-mcp/execution-authority`（`ExecutionAuthorityService`, `ExecutionAuthorityError`, `createSidecarExecutionIntentStore`, `ExecutionReservationPort`, `ExecutionIntentStore`, `ExecutionIntentRecord` ほか型） | `packages/company-os/execution-authority.js`（`Unson-LLC/brainbase-organization#1476`） |
| package export | `@unson/brainbase-mcp/execution-authority-http`（`createExecutionAuthorityHttpHandler`, `/execution-authority` ルート） | `packages/company-os/execution-authority-http.js`（`Unson-LLC/brainbase-organization#1476`） |

#### 移行手順
1. `@unson/brainbase-mcp/execution-authority` および `@unson/brainbase-mcp/execution-authority-http` からの import を、`brainbase-organization` の `packages/company-os/execution-authority.js` / `execution-authority-http.js`（または vendored された `@unson/brainbase-organization-company-os`）へ切り替えてください。
2. 組織版では PostgreSQL の intent store を利用します（OSS 既定の `createSidecarExecutionIntentStore` は移設対象外です）。
3. ルート・HTTP ステータスコード・エラーコード・保存レコード形式は維持されます。HTTP 入力検証の `invalid_request` メッセージは非 zod 化に伴い組織版の仕様に準拠します。

---

### 4. TypeScript 公開型の変更: `JudgmentOutboxPostAck['candidate_id']` / `JudgmentOutboxReadback['candidate_id']` を `string | null` へ拡張（`#1084` / RFC-002 PR-3b）

| Kind | Name | Note |
|---|---|---|
| type | `JudgmentOutboxPostAck['candidate_id']`（`@unson/brainbase-mcp/judgment-event-outbox`） | `string` から `string \| null` へ拡張。併せて任意の `candidate_created?: boolean` / `target_tier?: string` を追加。 |
| type | `JudgmentOutboxReadback['candidate_id']`（`@unson/brainbase-mcp/judgment-event-outbox`） | `string` から `string \| null` へ拡張。併せて任意の `candidate_created?: boolean` / `target_tier?: string` を追加。 |
| function | `deliverJudgmentKnowledgeEventOutbox`（`@unson/brainbase-mcp/judgment-event-outbox`） | `event.subject.type === 'episode'` かつ post / readback の双方が `candidate_id: null`（および明示された `candidate_created` / `target_tier` が `false` / `'episode'` と整合する）場合に限り `candidate_id: null` を受理。`decision`・`distilled_candidate`・`judgment_episode` 等の非 `episode` は引き続き非空文字列 `candidate_id` を必須とし fail-closed する。 |

#### 移行手順
1. `JudgmentOutboxPostAck['candidate_id']` / `JudgmentOutboxReadback['candidate_id']`（およびカスタム `JudgmentOutboxDeliveryPort['readback']` コールバック）の型注釈を `string` から `string | null` へ更新してください。
2. `POST /events` および `GET /cycles/:eventId` のアダプタで `candidate_id: null` を空文字へ変換せずそのまま保持し、`candidate_created` / `target_tier` が返る場合は転送してください。
3. 非 null な `candidate_id` が必須の呼び出し側では `if (ack.candidate_id !== null)` または新規エクスポートの `isValidJudgmentOutboxCandidateIdPair` で絞り込んでください。

## New & Changed since `0.50.31`

### Additive public surface
- **`@unson/brainbase-mcp/world-model-impact-index`（`#1044`）**: 世界モデルの逆引き影響インデックス（impact reverse-index）、反証リンク（refutation links）、および `graph-corrections` との補正ブリッジを追加。
- **`@unson/brainbase-mcp/judgment-event-outbox`（`#1084`）**: `JudgmentOutboxCandidateIdCheckInput` 型、`isValidJudgmentOutboxCandidateIdPair` ガード関数、`candidate_created?: boolean` / `target_tier?: string` フィールドを追加。
- **Canonical Task 契約（`#1010`）**: `canonical_tasks` 契約および `contracts/canonical-task/store-schema.sql` に nullable な予定開始時刻 `start_at`（`ADD COLUMN IF NOT EXISTS start_at TIMESTAMPTZ`）を追加。既存行・既存呼び出しとの後方互換を維持。

### Core runtime & MCP portability
- **MCP ツール schema ポータビリティ適用（`#1046` / `#1063`）**: `src/server.ts`・`src/judgment-frame.ts`・`src/mcp-runtime.ts`・`src/queue-task-tools.ts` に Gemini / OpenAI / Claude / Codex 互換の `inputSchema` 正規化プロファイルを統合（`0.50.29` `#1076` の強化済み `mcp-tool-schema-portability` 実装を保持）。`0.51.0` から `createServer()` および `createLocalMcpServer()` の `tools/list` は既定で `'gemini'` プロファイルにより正規化されます（lossless な標準 JSON Schema を維持したいホストは `schemaProfile: 'standard'` を明示指定できます）。
- **Judgment Host / Task Progress / Repository Discovery（`#970` / `#973` / `#976`）**: 有効な Git 作業ツリーのみを対象とする探索境界と、反復タスク準備後の再計画ゲート（`src/judgment-task-progress.ts`）を統合。
- **状態機械とリトライ境界の強化（`#1015` / `#1034` / `#1035` / `#1036` / `#968` / `#842`）**:
  - `automation-run`: runner 実行前の checkpoint 失敗を retryable 化し、遷移表とストア実装の一致をテストで固定。
  - `knowledge-continuation`: 完了済み lookup を取消で上書きしないよう修正し、状態遷移テストを追加。
  - `durable-waits`: 15 遷移の状態図・実装整合テストを追加。
  - `meeting-automation-runtime`: 会議生成前の実行契約を追加。
  - `routine-runtime`: Node 20 での深夜スケジュール計算を `hourCycle: 'h23'` に修正。
