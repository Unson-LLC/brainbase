## Changes since `0.51.3`

- **Antigravity CLI judgment hook の `toolSummary` ストリップと Gemini `nullable` 必須解除（`#1103` / `e67b2d2dc` / Item #172 / PR-A1）**:
  - `src/antigravity-judgment-hook.ts`: `normalizedToolInput()` で `mcp__brainbase__*` ツール入力（直接呼び出し・`call_mcp_tool` ラップ双方）から Antigravity が自動注入する合成 UI キー `toolSummary` のみをストリップし、他キーはそのまま保持して Host 側の厳格スキーマ検証を維持。
  - `src/mcp-tool-schema-portability.ts`: Gemini プロファイル（`BRAINBASE_MCP_SCHEMA_PROFILE=gemini`）正規化時に `nullable: true` なプロパティを `required` から除外し、`description` へ `Omit or pass null when unset.` を重複なく付与。`standard` プロファイル（Claude / OpenAI / Codex）は無損失・無変更を維持し、`allOf` 分割 `required` や own `__proto__` 保護とも整合。
  - `src/judgment-node-evidence.ts`: `previous_result_tool_use_id` が省略または `undefined` のノード証拠入力を `null` へ正規化し、Gemini の省略呼び出しを受理しつつ未知キー・不正型・シークレット混入文字列は fail-closed で拒否。
- **`judgment-node-evidence` の空文字 `previous_result_tool_use_id` 正規化（`#1094` / `5e902a369` / Item #184）**:
  - `cleanText()` で `nullable: true` 指定時に空文字・空白のみの文字列を `null` として正規化し、`previous_result_tool_use_id: ""` 等の境界入力でノード証拠が不要に棄却される問題を解消。
- **世界モデル再検証キューと読み取り専用 CLI の追加（`#1095` / `ffa57f8c5` / Item #236 / RFC-003 PR-1）**:
  - 新規公開 subpath `./world-model-revalidation-queue`（`src/world-model-revalidation-queue.ts`）と読み取り専用 CLI `brainbase world-model:revalidation-queue` を追加し、公開契約 fixture（`contracts/brainbase-public-contract.v1.json`）へ登録。
