# 0.41.1（npm公開前）

この版は、npm公開前の候補です。公開状態や本番画面への反映は、別途確認します。

## 議事録の所属を表示

議事録の一覧と詳細に、ホストが解決した所属プロジェクトのラベルを表示します。ラベルはテキストとして安全に描画し、共有UIが所属先を推測しません。

## 作成・編集の許可を反映

会議の作成と議事録の編集が許可されていない場合、該当するボタンやフォームを無効化または非表示にします。作成・保存・文書追加・版の確定の直前にも許可状態を確認し、画面を開いた後に権限が変わった場合の送信を防ぎます。

## 古い読み込み結果を適用しない

一覧や詳細の読み込みが逆順で完了しても、古い応答が新しい画面を上書きしません。絞り込み後に一覧から消えた会議は選択と詳細を解除し、古い詳細が再表示されることも防ぎます。

認証・認可と所属プロジェクトの解決はホストが担当し、共有UIはホストから渡されたラベルと操作可否を表示・制御します。
