# 0.29.0

## 追加

所有repoへのチームの文書の書き込みの検査と読み戻しの照合（`canonical-document-writer`）、知識の取り込みの提案と下書きの回答の検証（`knowledge-capture-preview`）、会議ソースのカタログ（`meeting-source-integration-catalog`）を、新しい出口として追加します（`story-document-and-meeting-source-exits-v1`）。brainbase-unsonの部品を処理を変えずに移したもので、Node.jsの標準モジュール以外に依存しません。外部のサービスを呼ばないので、OSSの既定の動作は変わりません。

## 修正

会議ソースの接続ごとの同期（`@unson/brainbase-mcp/meeting-source-connection` の `NativeMcpRuntime`）が、期限の切れたアクセストークンをrefresh tokenで更新するよう直します。これまではMCPのSDKが接続の提供者を非対話のクライアントとみなし、refresh tokenを使わずに「Either provider.prepareTokenRequest() or authorizationCode is required」で同期が失敗していました。更新が拒まれたときは `reauth_required` になります。
