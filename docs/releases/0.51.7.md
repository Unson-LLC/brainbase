## Changes since `0.51.6`

- **Antigravity CLI 判断フック Wave 2 修正（`#1109` / `7d633cb45` / Item #172・#330）**:
  - **Fix 2（`stripOrcaInjectedPreambles` — `UNS-7129` 修正）**: `src/antigravity-judgment-hook.ts` の `isOrcaScheduledTimePreamble` に線形時間の厳密な ISO-8601 暦・時刻・閏年・タイムゾーン検証を導入し、`25:00:00Z` や平年 `2026-02-29` 等の無効日時を誤剥離しないように修正。あわせて 0 件剥離（`strippedCount === 0`）の no-op パスで先頭・末尾の空白・タブ・改行を一切削らず原文のまま返すよう修正。
  - **Bug B Trap 2（`splitConcatenatedJsonTextBlocks` — Antigravity 連結テキスト末尾トレーラー復元）**: Antigravity CLI が `\n` 連結した Markdown 先頭ツール出力から、末尾の既知 MCP トレーラー最大 2 行（`{"connection_scope":{...}}` 単独行および `<!-- brainbase-knowledge-owner-audit:{...} -->` 単独行）を決定的に分離・復元するよう拡張。本文途中埋め込み・同一行連結・余計なキー・不正 `schema_version`・二重 `connection_scope` 等の偽装を拒否しつつ独立ブロック検証を通過できるように修正。
  - **回帰テスト追加**: `tests/antigravity-judgment-hook.test.ts` に Fix 2（無効日時・閏年・小数秒・no-op 空白保持・UNS-7080/7118/7123 回帰）および Bug B Trap 2（Markdown 先頭・0 件応答・JSON 先頭・偽装拒否・500k 線形時間・`PostToolUse` E2E）のテストを追加。
- **`0.51.6` 以降 `main` に既収録の修正（`#1068` / `29973bff0` / `UNS-4244`）**:
  - `src/brainbase-login.ts`: 端末ログイン時のデバイストークン応答本文が途中で読み切れなかった場合、期限内に限りポーリングを再試行するよう強化。
  - `src/claude-code-judgment-hook.ts`: Claude Code のターン開始時に登録 ID を記録し、判断フック再登録で ID が変わった場合は進行中ターンの後続イベント送信を停止して次のターンから新登録で送信するよう修正。
  - `tests/brainbase-login.test.ts`・`tests/claude-code-judgment-hook-registration.test.ts`: 上記の回帰テストを追加。

## Breaking changes

なし（`0.51.6` からのパッチ修正のみ）。なお、`#1068` に伴い更新時に進行中の Claude Code ターンで登録 ID を記録していないものは後続イベントの送信を停止し、次のターンから通常どおり送信されます（利用者操作は不要です）。
