# 0.38.0

## 追加

読み取り `GET /api/graph/people-and-companies`（`readGraphPeopleAndCompanies`）と、共通部品 `ui/people-and-companies-view`・`ui/people-and-companies-view.css` を追加します（`story-people-and-companies-read-v1`）。人ごとの有効な所属先の会社と関わるプロジェクトの数、会社ごとの所属者とプロジェクト（`owned_by`）、自社を返します。

自社は、Graphの本人（owner）の有効な所属がちょうど1社のときだけ決めます。0社・2社以上・本人の記録が無いときは `null` と理由を返し、画面は「自社が未設定」と出して全員を所属未確認に置きます。社内・社外の印は保存せず、返しません。

画面は読み取りのみです。直すときは「情報と関係」で同じ記録を開きます。

## 変更

Personal Web のメニューを、組織版と同じ6つの領域の見出しで束ねます（`story-shell-nav-six-areas-v1`）。「人と会社」は領域「情報と関係」の下に置きます。画面IDと初期画面は変わりません。
