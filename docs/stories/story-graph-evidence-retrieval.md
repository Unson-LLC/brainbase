# 質問から判断の根拠に到達する

利用者として、決定の名称を知らなくても、自分の質問から関連する決定を探し、組織・プロジェクトとの関係と本文を確認したい。候補の発見だけで根拠がそろったと判断してほしくない。

受入条件:

- 言い換えた質問をローカルの多言語意味検索で検索できる。
- モデルが指定した関係・方向を実在するGraph edgeでたどり、経路を返す。
- 廃止されたノードと関係を除外する。
- 本文と出典を候補に添付し、欠落・取得上限・未検証を明示する。
- 権限外の情報を返さず、API障害を該当なしに変換しない。
- 全体Hooks設定を変更しない。
