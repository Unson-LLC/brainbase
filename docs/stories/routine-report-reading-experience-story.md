# Story: 日次ルーティンレポートの読みやすさを統一する

おはよう・おやすみ・レトロを確認する佐藤さんとして、処理結果と未確認事項をそのまま読めるレポートが欲しい。不要なAI操作欄や意味のない `Untitled` が判断を妨げないようにするため。

## 受け入れ条件

- 3種類のHTMLに「AIに渡す次の指示」を表示しない。
- タイトルのない項目は本文を見出しへ昇格し、`Untitled`を表示しない。
- おはようの優先事項は「今日決めること」「今日の到達点」「AIが進めること」「持ち越し・未確認」に分ける。
- レトロは週次判断を読む順序で表示し、空欄を成功扱いしない。
- 既存のリンク、安全なHTMLエスケープ、実データ収集処理を壊さない。
