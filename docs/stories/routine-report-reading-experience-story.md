# Story: 日次ルーティンレポートの読みやすさを統一する

おはよう・おやすみ・レトロを確認する佐藤さんとして、処理結果と未確認事項をそのまま読めるレポートが欲しい。不要なAI操作欄や意味のない `Untitled` が判断を妨げないようにするため。

## 受け入れ条件

- 3種類のHTMLに「AIに渡す次の指示」を表示しない。
- タイトルのない項目は本文を見出しへ昇格し、`Untitled`を表示しない。
- 長い判断候補は太字の一段落にせず、「背景」「判断」「再利用できる考え方」「使う場面」「使わない場面」に分ける。
- 判断候補は短い見出しと「判断」「再利用できる考え方」を先に見せ、背景と適用条件は必要な時だけ開ける。
- 同じ候補は1件にまとめ、同じ状態はセクション見出しに集約し、空のセクションは表示しない。
- おはようの優先事項は「今日決めること」「今日の到達点」「AIが進めること」「持ち越し・未確認」に分ける。
- レトロは週次判断を読む順序で表示し、空欄を成功扱いしない。
- レトロは各セクションの先頭3件をまず表示し、残りは必要な時だけ開ける。
- 項目見出しの太字を抑え、意味のない証跡行は表示しない。
- 冒頭で全体量を把握でき、目次から目的のセクションへ直接移動できる。
- 長いセクションでも見出しを見失わず、本文と補足の強弱が一目で分かる。
- 朝・夜・週次それぞれの目的に合う最重要セクションを冒頭へ集め、情報源や補足より先に判断対象を読める。
- デスクトップでは現在地とセクション移動を左側に固定し、本文は読みやすい幅に保つ。モバイルでは同じ情報を上から自然に読める。
- セクションを同じ見た目で均等に扱わず、最重要領域と補足領域の差が画面を見ただけで分かる。
- 既存のリンク、安全なHTMLエスケープ、実データ収集処理を壊さない。
