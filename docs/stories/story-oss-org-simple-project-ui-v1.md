# OSSのプロジェクト画面を組織版の簡潔な見た目に揃える

利用者として、OSSのプロジェクト画面で必要な情報と操作をそのまま使いながら、組織版と同じ落ち着いた一覧中心の見た目で内容を読みたい。

## Controller

SIMPLIFICATION。既存のプロジェクト概要、一覧、詳細、Graphの機能・導線・データ境界を維持し、カード状の重複した枠を罫線ベースの一覧へ整える。情報設計、ホストAPI、データ、任意のWorld画面は変更しない。

## 受入条件

- AC-01: プロジェクトの文脈一覧とGraph候補一覧は、組織版の台帳と同様に、背景付きのカードを並べず、行と罫線で区切る。見出し、件数、各項目の選択・遷移は維持する。
- AC-02: 根拠項目も個別カードの枠を使わず、罫線と余白でまとまりを示す。選択状態、フォーカス表示、警告の色と意味は維持する。
- AC-03: Graphキャンバス、概要の指標、詳細画面、タブ、ボタン、データ状態の表示は維持し、操作・データ契約に変更を加えない。
- AC-04: 幅760px以下で一覧は一列になり、項目名・状態・操作が横にはみ出さない。

## 実装境界

- `ui/project-workspace.css` の既存部品だけを調整する。
- `ui/project-workspace.js`、API、Graph形式、画面遷移、組織版リポジトリは変更しない。

## 検証

- 既存のプロジェクト作業画面とGraph画面のUIテストを実行する。
- ビルドを確認し、差分レビューでカード枠が一覧表示に変わり、Graphキャンバスや状態表示が保たれていることを確認する。
