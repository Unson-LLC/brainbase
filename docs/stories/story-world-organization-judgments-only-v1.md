# 組織のGraphで描く世界には、その組織の判断だけを出す

## 利用者成果

組織のGraphから描いた世界を開いたとき、その組織の事業で作業した判断だけが見える。ほかの会社の仕事の判断（問い・作業場所）は、件数のほかは出てこない。

## 背景

世界は判断journalの全件を読み、事業に置けない判断を広場に、問いと作業場所つきで並べていた。判断の種類の建物も全件から作っていた。そのため、雲孫の組織Graphで描いた世界に、Tech Knight（別の会社）のリポジトリで作業した判断が出ていた。佐藤さんは「雲孫テナントでは表示されちゃいけない」と判断した（2026-10-05）。

## 受入条件

- [x] AC-01: 組織のGraphを読んでいるとき、世界は `GET /api/extensions/world/organization-judgments` だけから判断を読む。ホストは、作業したリポジトリがその組織の事業（登録リポジトリか事業コード）である判断だけで、判断の種類の集計と一覧を作る。
- [x] AC-02: それ以外の判断（ほかの会社のリポジトリ、作業場所の記録が無いもの）は、件数（`withheld`）だけを返し、問い・判断ID・作業場所・読めなかったファイル名を返さない。
- [x] AC-03: 世界の上部と広場に「この世界に出していない判断N件」を出し、「今日」では見られることを書く。一覧は出さない。
- [x] AC-04: 手元のGraphで描くときは、これまでどおり全件を読む。

## 対象外

「今日」の画面（本人の判断journal全体を出す画面で、組織の範囲ではない）。判断を「何についての判断か」で置く変更（W4）。

## 検証

- `tests/world-extension.test.ts` で、登録リポジトリと事業コードの判断だけが残り、別の会社のリポジトリと記録の無い判断が件数だけになり、返す内容にその判断IDと作業場所が含まれないことを確かめる。絞り込みを外すとこのテストが落ちることも確かめる。
- 実データのプレビューで、返す内容に `techknight` が含まれず、世界の上部に出していない件数が出ることを確かめる。
