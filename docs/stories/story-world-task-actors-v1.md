# 世界の現場に正本で確認した担当を表示する

世界の既存都市・仕事の現場に、ホストが同じTask IDで確認した担当を任意のactorsとして表示する。所属や登録、認可はホストの責任であり、共通UIに別保存先を作らない。

- 現場と選択欄に担当の名前を表示する。既存の人間担当を置き換えない。
- actors_stateが未確認、Task ID/状態の不一致は稼働として表示しない。
- 動きはTask in_progress、ホストの現在run稼働確認、受理済み、停止なし、新しいheartbeatが全部一致したときだけ。5分を超えると停止する。reduced motionでは常に静止。
- 未着手・待ち・完了・取消や外部MCPの未確認を動かさない。
- ファイル保管、成果・次の判断への表示、自動実行、登録は追加しない。

検証: tests/ui/world-task-actors.test.mjs と既存 world-work-rail/world-work。組織版は共通UIの公開版を依存pinして使う。未公開の変更が本番で動くとは扱わない。
