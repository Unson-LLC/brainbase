# 世界を、見て楽しい街の景色にする（データでない飾りはデータに見せない）

## 利用者成果

世界を開いた人として、事業の配置図ではなく街として眺めたい。夜には最近動いた都市の窓がいちばん明るく見え、前回開いてから何が動いたかが開いた瞬間に分かってほしい。

## 原則

景色（空・海・陸・山・木・畑・街灯・噴水・公園）はデータを表さない。何かを表すと読まれる演出（窓の明かり、変化の印）は、必ずデータから出す。家は案件と読まれるので、案件以外には置かない。

## 受入条件

- [x] AC-01: 都市の外側に陸・砂浜・海・遠くの山並みと霧を描き、台座が宙に浮いて見えないようにする。
- [x] AC-02: 広場の中央に噴水を置き、都市と広場を結ぶ道を並木と街灯の大通りにする。都市の間には林と畑を置く（家は置かない）。
- [x] AC-03: 空は端末の時刻に合わせて夜明け・昼・夕方・夜に変わる。見る人は昼・夕方・夜に固定もできる。夜は窓の明かりと街灯がいちばん強く光る。窓の明かりの意味（最近30日の動き）は変えない。
- [x] AC-04: 完了・終了した案件は更地ではなく、小さな記念の公園（芝・石・低木）として描く。
- [x] AC-05: 前回開いた時刻をこのブラウザに覚え、それより新しい決定・判断がある都市と広場の建物に、短い光の粒と地面の輪を出す。初めて開いたときは何も出さない。覚えられないブラウザでも画面は壊れない。

## 対象外

建設中の足場、道を走る光、港と船、人影（第2段。データの根拠ごとに足す）、開いたときのカメラの一周、寄ったときの地上目線。

## 検証

- `tests/world-extension.test.ts` で、時刻と空の対応、前回からの変化の判定（初回は無し、より新しいものだけ）を確かめる。変化の判定を壊すとテストが落ちることも確かめる。
- 実データのプレビューと、GPUのあるChromeで、景色と変化の印が描かれ、コンソールのエラーが無いことを確かめる。
