# 世界に「あなたを待っている」の短い一覧を出す

## 利用者成果

朝に世界を開く本人として、自分を待っている判断を3D の中で探さずに、数件を一度に見て押し、判断の履歴の同じ判断へ降りたい。

## 背景

- brainbase-project の前提台帳は 2026-10-11 に U2 を採用し、P17 に「世界に、あなたを待っている判断の短い一覧を足す」を追記した。原則は「平常時は俯瞰、異常時だけ深掘り」のままで、例外の分だけを一覧にする。
- 世界はすでに待っている判断を光の柱と件数で示しているが、件数と建物しか無く、朝に押せる一覧が無かった。
- 判断の履歴への降り口は `judgmentHref`（story-judgment-history-nav-v1）を使う。

## 受入条件

- [ ] AC-01: 待っている判断（`needs_human` で、回答も会話での前進も無いもの）を新しい順に最大3件、「待っている判断」として出す。各行は本来の質問の文と「「判断の履歴」で開く」のリンクを持ち、リンクは `judgmentHref(decision_attempt_id)` へ降りる。
- [ ] AC-02: 3件を超える分は隠さず「ほかN件は「判断の履歴」で見られます」と出す。
- [ ] AC-03: 待っている判断が0件のとき、一覧を出さない。
- [ ] AC-04: 判断の記録を読めないとき、一覧を出さず、待っている判断が0件とも出さない。
- [ ] AC-05: キャンバス表示と標準表示の両方で同じ一覧を出す。

## 範囲外

- 一覧から直接答えること。回答は会話（P1・P13）で行う。
- 組織版での配備（OSS の公開版を取り込む別の変更）。
