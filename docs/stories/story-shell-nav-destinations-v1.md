# 左側に行き先そのものを小見出しで並べ、領域の中のタブは設定の中だけにする

## 利用者成果

Brainbase の Web を開く本人として、左側を見ればそのまま行き先が分かり、1回押すだけで毎日使う画面に着きたい。2026-10-17、佐藤さんは段階2（6つの領域と、領域の中のタブ。[story-shell-nav-area-tabs-v1](./story-shell-nav-area-tabs-v1.md)）を本番で使い、「メニューは見やすいが、その先がとても分かりにくい。動線も見にくい」と述べた。領域を押してからタブを探す2段階になっていて、行き先が左に見えなかったため。

## 背景

- brainbase-project の前提台帳（`docs/architecture/oss-personal-web-ux-premises.md`）の D10。2026-10-17 の改訂（brainbase-project #114）で、左に行き先そのものを小見出しで並べ、領域の中のタブをやめると決めた。タブは、設定の中のように同じものを違う面から見るときだけにする。
- 並び: 上段（小見出しなし）受信箱・世界・タスク・アプリ／会議（予定・議事録・振り分け待ち）／プロジェクト（星を付けたプロジェクト・目的と現状。全件の一覧は区画の見出しから開く）／調べる（知識・判断の履歴・情報と関係・人と会社・あなたの記憶・取り込み待ち）／左下に設定（中にメンバーと権限・情報の種類とつながり方・開発者）。OSS Personal に無い画面は出さず、区画の中が空になれば見出しも出さない。
- 部品は OSS の共通UIに作り、組織版はそれを組み込む（D8・P16）。組織版の組み込み、星の置き場、受信箱の画面（D16）は、このStoryの範囲外。

## 受入条件

- [ ] AC-01: 共通部品 `ui/area-nav.js` が、任意の `sections`（区画）を受け取る。区画は小見出し（無しも可）と置き場（本体か左下か）を持ち、行き先（`areas` の各行）を `section` で区画に入れる。区画を指定しない行は、これまでどおり小見出しなしで並ぶ。`sections` を渡さない呼び出し（組織版の今の組み込み）は、今の表示と振る舞いのまま変わらない。
- [ ] AC-02: 区画の見出しは、指定した画面へのリンクにできる（プロジェクトの全件の一覧）。押すとその画面を開き、その画面を見ている間は見出しを今の場所として示す。その画面が隠れていれば、見出しは文字だけにする。
- [ ] AC-03: 呼び出し側が、区画の頭に行き先を差し込める（星を付けたプロジェクト）。差し込んだ行は、名前とアドレスと、待っているものの件数を持てる。行を空にすれば消える。
- [ ] AC-04: 見える行き先が1つも無い区画は、見出しごと出さない。
- [ ] AC-05: 画面が2つ以上ある行き先（設定）だけが、本文の上にタブを出す。画面が1つの行き先はタブを出さない（story-shell-nav-area-tabs-v1 の AC-04 のまま）。
- [ ] AC-06: OSS Personal の左側は、上から 世界の拡張（あれば）／会議: 議事録／プロジェクト（見出しから「プロジェクトと関係者」を開く）: 目的と現状／調べる: 判断の履歴・情報と関係・人と会社・あなたの記憶 と並び、左下に「設定」（情報の種類とつながり方を開く）を置く。領域を持たない拡張の画面は、これまでどおり先頭または末尾に1行ずつ並ぶ。
- [ ] AC-07: OSS Personal の画面ID（`#value-proofs` など）、初期画面、`LOCAL_WEB_SCREENS` の並びは変えない。

## Spec

- 振る舞いは `tests/ui/area-nav.test.mjs`（部品）と `tests/ui/local-web-shell.test.mjs`（OSS Personal の組み込み）で固定する。
- 部品は DOM を作るだけで、画面の表示・読み込みは呼び出し側が持つ。追加の操作は `setLinks(sectionId, links)` だけ。見出しの画面を開くときも `onSelect(screenId)` を呼ぶ。
- 前回の画面の記憶（`createAreaMemory`）は、画面が2つ以上ある行き先にだけ効く。保存の形は変えない。

## 範囲外

- 組織版への組み込みと、本文の上のプロジェクトの選択の扱い（組織版の Story。台帳 §6 の 10 で佐藤さんが決める）。
- 星の付け外しの操作と置き場（台帳 §6 の 10）。部品は差し込まれた行を描くだけにする。
- 受信箱の画面と集約のAPI（台帳 D16）。
