# 案件が少ない事業でも、世界が最後まで描かれる

## 利用者成果

案件が1〜3件しか見えない事業があっても、世界は全部の事業と案件を描く。権限の範囲が狭いメンバーでも、世界が途中で欠けない。

## 背景

組織版に世界を載せる確認（2026-10-05）で、案件が2件の事業を描いた時点で例外が出た。区画の格子が2×2のとき、4つの区画がすべて都市の中央（目印の場所）に入り、置き場が0件になっていた。例外で描画が止まり、それ以降の事業も描かれなかった。

## 受入条件

- [x] AC-01: 区画の数がいくつでも、目印の場所を除いた置き場がその数以上ある（足りなければ格子を広げる）。
- [x] AC-02: 置き場は目印の場所と重ならない。

## 検証

- `tests/world-extension.test.ts` で、0・1・2・3・4・8・9・10・25件の区画に置き場が足り、目印と重ならないことを確かめる。
- 組織版の確認用サーバーで、案件2件の事業を含む世界が例外なく描かれることを確かめる。
