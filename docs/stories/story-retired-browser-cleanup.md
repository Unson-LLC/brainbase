# 退役したブラウザセッション・端末実装の除去

Story ID: `retired-browser-cleanup`

利用者として、Brainbaseが所有しない旧セッション・端末実装を現役コードと混同せず、現在の責任境界を理解・保守したい。

## 受入条件

1. 現役の静的入口とserverから到達しないことを確認した旧セッション・端末の実装を、その専用テストと一緒に除去する。残るコードに削除先へのimportを残さない。
2. `/device`の認証画面・コントローラー、Graph、MCP、Run Receiptは保持する。旧APIの410と旧UI入口の退役を維持する。
3. 履歴契約テストは過去の文書を参照するだけとし、退役実装の存続を要求しない。
4. 除去する能力の文書は現役の起動・復旧手順として案内しない。過去のsession/archiveデータは変更・削除しない。
5. 影響するテスト、独立レビュー、CIで検証する。

## 境界

ADR-019の実装継続。新たな所有権変更ではない。前提PR #1646に積む。全レガシー削除・本番デプロイ・過去データの移行/削除・外部runtimeの変更は対象外。
