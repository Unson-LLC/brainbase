# RQ008: 区画を開いたまま自動の空を更新する

自動モードの区画もブラウザのローカル時刻に追従し、画面を開き直す必要をなくす。

## 受け入れ条件

- 開いた区画で昼→夕方→夜の境界を越えると、空・霧・照明を同じ skyAt 定義で更新する。
- 手動モードは時刻で変えない。autoへ戻すと現在時刻を反映する。
- reduced motionでも更新し、非表示/サスペンド後の再開で追従する。
- 時刻境界、循環順、アイコンの仕様は変更しない。

## 最小仕様

表示中の frame で実時間の分を比較し、autoかつ skyAt の phase が変わった場合だけ既存 applySky を呼ぶ。フレーム時間から日時を計算しない。

## 境界

OSS共有UIの修正。組織版の現在の npm pin への取り込みには別途公開済み版が必要。パッケージ公開と手動配備は今回行わない。
