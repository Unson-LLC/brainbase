# 組織版でこの記録を開くリンクを、最初に目に入る場所に置く

## 利用者成果

組織のGraphを読み取り専用で見ている本人が、直したい記録を開いたとき、画面の上部ですぐ「組織版でこの記録を開く」を押せる。世界で都市や区画を選んだときも、そこから組織版の同じ記録へ移れる。詳細の一番下までスクロールして探さずに済む。

## 背景

佐藤さんが世界の画面で「組織版でこの記録を開く」を探したが見つからなかった（2026-10-05）。リンクは「プロジェクトと関係者」「情報と関係」の詳細の最下部にだけあり、画面上部の「出典」にあるリンクは画面単位（`?screen=projects`）で、押しても記録は開かなかった。世界の右パネルには組織版へのリンクが無かった。

## 受入条件

- [x] AC-01: 組織のGraphを読む「プロジェクトと関係者」「情報と関係」で記録を選ぶと、上部の「出典」のリンクが「組織版でこの記録を開く」になり、その記録を指す（詳細の案内と同じ行き先）。記録を選ぶ前は、これまでどおり画面単位の「組織版で開いて訂正する」。
- [x] AC-02: 世界で都市（事業）や区画（案件）を選ぶと、右パネルの「詳しく見る」に「組織版でこの記録を開く」が出て、そのプロジェクト自身のコードで組織版の「プロジェクトと関係者」を開く。自身のコードが無いものは記録IDで「情報と関係」を開く。
- [x] AC-03: 組織のGraphを読んでいない、または組織版の場所が渡されていないときは、どちらのリンクも出さない。
- [x] AC-04: 詳細の案内（①〜③）は残し、①に上部の「出典」にも同じリンクがあることを書く。

## 対象外

組織版側の変更、案内の文言の権限の説明（#662で確定済み）。

## 検証

- `tests/ui/local-web-shell.test.mjs` で、記録を選ぶと上部の「出典」のリンクが記録を指し、画面単位のリンクが残らないことを確かめる（リンクを記録に向けないとこのテストが落ちることも確かめる）。
- `tests/world-extension.test.ts` で、区画が自身のコードを持つ（無ければ null）ことを確かめる。
- 実データのプレビューで、「プロジェクトと関係者」の上部のリンクが記録を指すことを確かめる。世界の右パネルは3Dのクリックが要るため、佐藤さんの確認に委ねる。
