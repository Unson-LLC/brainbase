# 世界で押せそうに見える所は、押すと行き先へ進むか、押せない理由が見て分かる

## 利用者成果

世界を開いた本人として、押せそうに見える行・建物・看板を押したら、その中身へ降りたい。押せない所は、押す前に押せないと分かり、なぜ押せないのか（未接続など）が分かっていたい。

## 背景

- 2026-10-16、佐藤が組織版（雲孫）の世界を使って指摘した。
  - 左上の一覧（「判断の記録」「振り分けを待っている会議」など）が押せそうに見えるのに、押しても何も起きない。件数が出ても次にやることにつながらない。
  - 町の中の広場が押せず、何なのかも分からない。
  - 「1件の所」と「6件の所」の違いが分からない（件数を押して中身へ進めない）。
- 本番と同じ共通コア 0.41.7 で再現した原因:
  - 左上の一覧は、行き先があっても行の中の小さな文字だけがリンクで、行そのもの（ボタンに見える枠）は `pointer-events: none` で押せない。行き先の無い行も同じ見た目をしている。
  - 「記録の要確認 N件・M事業」と区画の中の「記録の要確認 N件」には行き先が無い。
  - 世界の広場は押すと寄るだけで、説明はキャンバス表示では閉じた右の引き出しに入るため見えない。さらに判断が未接続でも「どの事業にも置けない判断（0件）ありません」と出す（P9に反する）。
  - 区画の通りの看板（「〇〇（1件）」「〇〇（6件）」）と庁舎・庁舎前の広場は、押せる物として登録されていない。
  - 判断所・判断の種類の「「判断の履歴」で開く」ボタンは `location.hash` に行き先を入れるため、組織版の `?screen=value-proofs` では `#?screen=…` になり行き先に着かない。
- 前提台帳 P9（未接続や不明を0件や空に見せない）、P17（例外は押して降りられる短い一覧として出し、0件なら出さない。町として見せる）、P16・D8（直しはOSSの共通UIで行い、組織版でコピーしない）。

## 受入条件

- [x] AC-01: 左上の一覧で行き先（`link`）のある行は、行全体が押せて、押すとその行き先へ進む。行き先の文字の後ろに「›」が付く。
- [x] AC-02: 左上の一覧で画面の中の行き先（`action`）のある行は、行全体がボタンになり、押すとその処理を行う。
  - 世界の「記録の要確認 N件・M事業」→ 右の引き出しに区画の入口（要確認の多い順）を開く。
  - 区画の中の「記録の要確認 N件」→ 右の引き出しにその都市の詳細を開く。
- [x] AC-03: 行き先の無い行は、押せる行と違う見た目（点線の枠・影なし）で、押しても何も起きないと分かる。理由（`reason`）が渡されたときは行の中に出す。判断の記録が未接続の行には「各メンバーのMacにあり、組織版には送っていません」を出す。
- [x] AC-04: 世界の広場を押すと、キャンバス表示でも右の引き出しが開き、広場が何か（判断の種類を建物として並べる所）を説明する。判断の記録が未接続または読めないときは、その理由を出し、「どの事業にも置けない判断（0件）」「ありません」を出さない。広場の名札は「広場（判断：未接続）」とする。
- [x] AC-05: 区画の通りの看板（「〇〇（N件）」）を押すと、その通りの仕事N件を右の引き出しに一覧で出し、街の中でその仕事を濃く、ほかを薄く出す。一覧から選ぶとその仕事の根拠が開く。
- [x] AC-06: 区画の庁舎・庁舎前の広場とその名札を押すと、右の引き出しにその都市の詳細（目的・方針）を開く。
- [x] AC-07: 案件・判断所・判断の種類を押したときも、キャンバス表示では右の引き出しを開く。「「判断の履歴」で開く」はホストの行き先（`judgmentHref(null)`）へのリンクにし、`#`で始まらない行き先でも着く。
- [x] AC-08: 町として見せる形（P17）と、行き先の無いときの今までの表示（標準表示）は変えない。

## 検証

- 試験: `tests/ui/world-clickable-honesty.test.mjs`（8件。変更前のコードでは8件とも落ちる）。世界のUI試験一式も合格。
- 実ブラウザ（Chrome、1440×900と390×844）: 組織版と同じ引数（`presentation: 'canvas'`、組織のGraph、判断は `judgment_journal_not_connected`、会議の振り分け3件・記憶の候補2件）で共通コア0.41.7の変更前と変更後を並べて押した。
  - 「振り分けを待っている会議」の行の文字を押す → `?screen=meeting-triage` へ進む（変更前は行き先の小さな文字以外は反応なし）。
  - 「判断の記録：未接続」の行を押す → 何も起きず、行の中に「各メンバーのMacにあり、組織版には送っていません」。
  - 「記録の要確認 12件・5事業」を押す → 区画の入口が要確認の多い順に開く。
  - 広場を押す → 広場の説明と「判断の記録：未接続…広場に建物が無いのは、判断が0件だからではありません」。
  - 区画の看板「組織版の配備（6件）」を押す → その6件の一覧（変更前はcanvasが押下を受け取り、看板は押せなかった）。庁舎を押す → 都市の詳細（目的と方針）が先頭から開く。
  - 押したときに地図（`bb-world-stage`、overflow: hidden）が126px上にずれていた既存の不具合も直した（引き出しの中だけをスクロールする）。
- 前後の画像（見本データ）: `docs/ux-research/world-clickable-honesty-20261016/screenshots/`
