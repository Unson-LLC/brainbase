# 判断履歴の取得済み件数と全件数を区別する

本人として、判断履歴が一部しか取得できないときに、画面に出ている件数を全件数と取り違えず、取得済みの範囲と未確認の範囲を理解したい。

## 受け入れ条件

1. 全件取得が確認できない応答では、表示済み件数と全件数未確認を同じ集計欄で示す。
2. 全件取得済みの応答では従来どおり全件数を示す。
3. 追加ページがある場合も、先頭ページの件数を全件数と表示しない。
4. 空のpartial応答を判断0件と断定しない。
5. 認証された本人とprojectの認可、取得元の警告、参照と実行結果の未確認を維持する。

## 範囲

表示の確実性を修正する。既存履歴の再送・補完、未接続取得元の接続、走査上限の増加は行わない。永続indexによる全件集計は別のデータ契約として設計する。
