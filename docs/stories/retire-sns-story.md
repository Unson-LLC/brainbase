# SNS機能の廃止

## 利用者の意図

SNS運用をBrainbaseの対象から外し、T0 → A0 → P0 → G0の本番検証に集中する。
既存の投稿台帳は保全し、個人知識・認証・テナント境界・知識昇格は継続する。

## 受け入れ条件

- SNS APIは廃止済みの応答を返し、投稿・DB・権限発行を実行しない。
- SNS専用CLIと予約実行の入口から投稿や知識への書き込みが起きない。
- 共通M5-A移行からSNS台帳を除外し、SNS専用DB設定を共通移行先に使わない。
- 既存台帳の削除・帰属変更・バックフィルは行わない。
- 共通知識機能の回帰テストを通す。本番停止確認はローカル合格と別に報告する。
