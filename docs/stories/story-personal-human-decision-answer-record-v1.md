# 人に戻した判断に、見返し画面から回答を記録できる

## 利用者成果

所有者として、AIが「あなたの判断が必要」として戻した問いに、見返し画面で選択肢を選んで回答し、その回答が記録されたことを確かめたい。評価（実行後の振り返り）と回答・承認を取り違えたくない。回答を記録しても、止まった作業が自動では再開しないことも分かっていたい。

## 所有と対象

- 登録・実装repo: `Unson-LLC/brainbase`
- 対象: 回答の追記記録（`brainbase-judgment-value-proof-answer-v1`、`judgment-value-proof-answers.jsonl`）、見返しのHTTP（`POST /answers`）、見返し画面の回答の操作
- 設計の元: PR #642 `story-personal-human-decision-answer-web-v1`（設計のみ）の候補のうち、回答の正本を判断の記録と別の追記記録に置く案（S2）と、再開しない記録のみの案（T3）を採る。

## 受入条件

- [ ] AC-01: 回答できるのは「あなたの判断が必要」に分類され、人への問いと選択肢がある判断だけ。選択肢のどれか1つ、または「どれも選ばない」を記録する。それ以外の判断と、問いに無い選択肢は記録しない。
- [ ] AC-02: 回答は判断の記録（`.value-proof.json`）を書き換えず、別の追記記録に残す。記録は、判断の識別子、その時点の問いの本文のdigest、選んだ選択肢、送信前の確認を経たこと、作業を再開していないことを持つ。
- [ ] AC-03: 同じ判断へ同じ回答を再送すると同じ記録を返し、違う回答は上書きせず競合として拒否する。同時に書き込んでも、1つの判断に2つの回答が残らない。
- [ ] AC-04: HTTPの回答の書き込みは、評価と同じく同一オリジン・起動トークン・既知の判断を要求し、送信前の確認（`confirmed: true`）がない書き込みを拒否する。
- [ ] AC-05: 見返し画面は、人に戻した判断の詳細に、選択肢ごとの回答の操作と、回答の意味（記録されるが作業は自動で再開しない、記録後はこの画面で変更・取り消しできない）を出す。押すと確認を挟んでから記録し、読み戻せた場合だけ「回答を記録しました」と出す。
- [ ] AC-06: 回答済みの判断は「あなたの判断が必要」の件数と絞り込みから外し、詳細に記録した回答と日時を出す。評価の欄は「回答や承認ではない」の案内のまま残す。
- [ ] AC-07: 問いのあと同じ会話で次のやり取りがあった判断は、会話で先に進んだものとして「あなたの判断が必要」の件数と絞り込みから外し、回答の対象にしない。会話の中で答えたのか話が変わったのかは区別できないので「回答済み」とは書かず、「会話で先に進んだ」と出して、続きは元の会話で頼むよう案内する。

## 対象外

作業の自動再開、回答の変更と取り消し、本人の証明（起動トークンは本人の証明ではない）、組織版での回答、会話（MCP）からの回答、Graphへの書き込み。

## 検証と完了

記録・競合・読み戻しは一時ディレクトリの実ファイル、HTTPは実サーバー、画面は簡易DOMで確かめる。利用者に効いたかは、常駐のPersonal Webで、画面を点検する担当が UX-20261002-02 を「確認済み（直った）」と判定したときに確かめたとする。
