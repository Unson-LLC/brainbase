# 世界の建物・地面・街並みの作りを上げ、街として見て楽しい品質にする

## 利用者成果

世界を開いた人として、箱の並んだ配置図ではなく、作り込まれた街として眺めたい。昼も夜も、建物の形と明かりから事業の種類と最近の動きが読めてほしい。

## 原則

データの意味は変えない。建物の形＝事業の種類、高さと窓の明かり＝最近30日の動き、案件1件に家1軒、終わった案件は公園、という対応はそのまま。基壇・軒・屋上設備・柱廊・ドア・煙突などの細部は飾りで、それ自体は何も表さない。

## 受入条件

- [x] AC-01: 地面と海は繰り返しの絵柄を使わず、頂点の色のゆらぎで塗る。地面に縞が出ない。
- [x] AC-02: 窓は壁にだけ付け、屋根は無地にする。光る窓は建物ごとにまばらで、市松模様の繰り返しに見えない。
- [x] AC-03: 種類ごとに形を作り込む（プロダクト＝基壇と段のあるガラスの塔、顧客案件＝柱廊と切妻屋根の館、研究＝窓のある円筒とドーム、社内・その他＝屋上設備のある事務所棟）。全体の高さは今と同じ式で決める。
- [x] AC-04: 都市は縁石の段と街灯のある街区にし、道は歩道・アスファルト・破線の中央線にする。木は針葉樹と広葉樹を混ぜる。
- [x] AC-05: 夜は街灯の下に柔らかい光だまりが出る。雲は島の奥の海の上だけに浮かび、都市を隠さない。
- [x] AC-06: 建物にマウスを重ねると強調され、選ぶと右の欄が開く（壁と屋根で材質が分かれても変わらない）。

## 検証

- 同じ視点の昼・夜・寄り・引きの画像を、変更前と変更後で比べる（GPUのあるChrome）。
- 地面の縞が影の偏りではなく絵柄の繰り返しから出ていたことを、影の設定だけ変えた画像と、地面を無地にした画像で確かめる。
- 実データで、マウスを重ねたときの強調、都市を選んだときの右の欄、コンソールのエラー0件、毎秒のコマ数を確かめる。
