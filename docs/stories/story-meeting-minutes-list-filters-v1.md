# 議事録の一覧を、条件で絞り込み、並べ替えて探す

利用者として、議事録の一覧から目的の会議を、スクロールして探さずに見つけたい。会議名の一部、期間、参加者、確認の状態で絞り込み、会議の日時や更新の順に並べ替えたい。作成できないときは、その理由だけを一言で知りたい。

2026-10-16、佐藤さんが組織版の議事録の画面で「プロジェクトの絞り込みは検索できるカスタムのプルダウンにしたい」「絞り込みの条件が弱すぎる」「並べ替えもできるようにしたい」「『会議を作成する権限がありません。作成はプロジェクトの編集権限がある人が行います』の意味が分からない」と指摘した。組織版では、作成できない本当の理由は権限ではなく「プロジェクトを選んでいない」ことだった。

## Controller

ADDITION。共通UI `ui/meeting-minutes.js` の一覧の上に、絞り込みと並べ替えの帯を足す。プルダウンは共通部品 `workspaceCombobox`（story-workspace-searchable-dropdown-v1）を使う。HTTPの契約・正本の記録は変えない。組織版は、この帯にプロジェクトの選択肢を渡すだけにし、自前の絞り込みを作らない（台帳 P16・D8）。

## 受入条件

- AC-01: 一覧の上に、会議名・議事録名のキーワード、期間（から・まで）、並べ替えを出す。条件を変えると、読み込み直さずに一覧が絞り込まれる。
- AC-02: 参加者の絞り込みは、読み込んだ会議に参加者の記録があるときだけ出す。確認の状態（確認待ち・確認済み）の絞り込みは、一覧に確認の状態が出せる会議があるときだけ出す。記録の無い条件を空の選択肢で見せない（P9）。
- AC-03: 並べ替えは「会議の日時が新しい順」（既定、今までと同じ）「会議の日時が古い順」「議事録の更新が新しい順」。日時順では日付の見出しで区切り、日時の無い会議は最後に置く。更新順では見出しを付けず、各行に更新の日時を出す。
- AC-04: 件数は、条件があるときは「全体の件数中の件数」で出す。条件に合う会議が無いときは「条件に合う会議はありません」と出し、条件を外すボタンを出す。会議がまだ無いこと・読み込めなかったことと区別する（読めないことを0件に見せない）。
- AC-05: ホストは `hostFilters` で、帯に自分の絞り込み（組織版ではプロジェクト）を足せる。選択肢・値・変更時の処理はホストが持ち、帯は共通のプルダウンで描く。
- AC-06: 作成できないときは「会議を作成」を押せない形で出し、ホストが渡した理由（`createUnavailableReason`）を一言だけ添える。理由が無ければボタンを出さない。権限の説明の段落は出さない。

## 実装境界

- 絞り込みと並べ替えは、読み込んだ一覧の表示だけを変える。正本の記録・HTTPの問い合わせは変えない（ホストの絞り込みがホスト側で問い合わせを変えるのは、ホストの責任）。
- 組織版の画面への組み込み（プロジェクトの選択肢、作成できない理由の文言）は brainbase-organization 側で行う。

## 検証
