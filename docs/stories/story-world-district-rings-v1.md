# 事業の区画は、庁舎を中心に輪で外へ広がる

事業の中身（仕事）が増えても、区画が一方向へ長く伸びないようにする。庁舎と広場を中心に置き、仕事の集まりを扇形に分け、輪の道に沿って内から外へ建物を並べる。世界（広場から道が伸びる）と同じ作りにそろえる。

これまでの区画は、1本の大通りに沿って集まりを縦に並べていた（story-world-work-sites-and-gaps-v1 の AC-12・16・17 の配置）。仕事が増えると長さだけが伸び、全体を一目で見られなくなる。配置の決まりだけをこのStoryで置き換える。建物の意味・看板の言葉・成長の段階は変えない。

## 配置の決まり

- 中心は庁舎と広場。門は手前にあり、門から広場まで大通りが1本通る。
- 同じ目的（`purpose_label`）の仕事は1つの集まりで、円の扇1つを占める。扇は門の大通りから時計回りに、いちばん古い仕事の順に並ぶ。目的の記録が無い仕事は最後の扇（門の脇）に置く。
- 扇の中では、作成順に、広場に近い輪から外の輪へ埋める。輪の上の場所は固定で、扇の真ん中から埋める。
- 仕事が増えると、輪が1つ外に増える。件数が10倍になっても、幅は3倍未満に収まる。
- 扇の幅は、件数の粗い段階（4件まで1、16件まで2、36件まで3…）の比で決める。1つの集まりだけが大きくても、町は丸いままになる。
- 集まりの数が多い事業は、最初の輪に全部の扇が1区画ずつ入るように、広場が広くなる。

## 動かないこと

- 集まりの中に仕事が増えても、状態が変わっても、ほかの建物は動かない。
- 扇を割り直すのは、集まりが増えた・無くなった・件数が段階をまたいだ、のいずれかのときだけ。

## 見え方

- 輪の道は円で描き、扇の境に細い道を通す。まだ建っていない場所は緑にし、一部に木を置く。
- 集まりの看板は広場の縁に立ち、名前は集まりの建物の上に出す。
- 町が広いほど、全体を見るカメラは遠くなる。カメラの届く距離・霧・影の範囲も町の広さに合わせる。
- 通りへ寄るときは、その扇の建物が収まるところへ寄る。向きは区画全体と同じにする。
- 名札は左下のパネルの下にも入らない。寄った集まりの名札どうしは重ねず、選んだ・指した名札だけは必ず出す。
