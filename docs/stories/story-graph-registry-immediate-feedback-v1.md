# 情報と関係で、押した結果と絞り込んだ結果をその場で見る

利用者として、「情報と関係」の検索結果を押したら、押した行のすぐそばに、どの記録の詳細かが分かる形で中身を見たい。絞り込みは、変えたらすぐ一覧に反映され、今かかっている条件が見えて、条件ごとに外せるようにしたい。

2026-10-16、佐藤さんが組織版の「情報と関係」で次のように指摘した（記録 14-5・14-6・14-7・14-9・14-10・14-18）。

- 検索結果を押しても何も出てこないか、出ていても別の場所（下や横）が変わっていて、何も起きていないように見える。「動線として最悪」
- 他の画面は絞り込むとすぐ反映されるのに、ここだけ「探す」を押さないと反映されない
- 絞り込みの外し方が分からない。名前で検索した後、空欄でもう一度検索しないと外れないように見える
- 「有効時点」の意味が分からない
- 「要約」の列は、ありと無しがあるが、その差が分からない
- 「記録の詳細」が、何に紐づいた詳細なのか分からない

実ブラウザ（組織版と同じ3列の枠・同じCSS・組織版と同じ形の応答）で確かめると、幅1440pxでは詳細が右の欄だけで変わり、幅1040px以下では詳細が一覧の下の約2,000px先に出て、押した位置からは何も変わらなかった。名前の欄に打っても、「探す」を押すまで一覧は変わらなかった。

## Controller

MODIFICATION。共通UI `ui/graph-registry-view.js` の検索の帯・検索結果の一覧・選んだ記録の詳細の置き場所を変える。HTTPの契約・正本の記録・訂正の流れは変えない。組織版はこの部品をそのまま組み込み、自前で作り直さない（台帳 P16・D8）。

画面全体の構成（自分の束・情報の種類とつながり方の置き場所）は、別のStory（情報と関係の画面の構成を作り直す）で扱う。

## 受入条件

- AC-01: 検索結果の行を押すと、その行のすぐ下に詳細を開く。詳細の見出しに、記録の名前と種類と「選んだ記録の詳細」を出す。同じ行をもう一度押すか「閉じる」で閉じる。開いた詳細の見出しが画面に入るように動かす。
- AC-02: 詳細から関係の相手をたどったときも、同じ場所で開き、見出しは今見ている記録の名前にし、たどり始めた行の記録と「前の記録に戻る」を出す。一覧に無い記録（アドレスで指した記録など）は、一覧の上に開く。
- AC-03: ホストが右の欄を渡しているときは、右の欄に詳細を重ねて出さない。右の欄には、何も開いていなければ「行を押すと、その行の下に詳細を開きます」、開いていれば開いている記録の名前と、そこへ移るボタンを出す。
- AC-04: 名前・別名の欄は、打つのを止めて少し待つと一覧に反映する。日本語の変換中は反映しない。Enterで待たずに反映する。種類は共通のプルダウン（`workspaceCombobox`）で選び、選んだらすぐ反映する。「探す」ボタンは置かない。読み直しの間も前の一覧を消さず、「探しています」と添える。
- AC-05: 条件があるときは、一覧の上に今の条件を札で並べ、札ごとに外せる。「すべて外す」で全部外す。
- AC-06: 「有効時点」は「詳しい条件」の中に下げ、「この日に有効だった記録だけ」と書く。札には「◯◯の時点で有効なもの」と出す。
- AC-07: 要約が無い記録は、一覧でも詳細でも「要約は未登録」と出す。読めない状態や空欄に見せない（P9）。
- AC-08: 記録や関係のIDの折りたたみは「この記録のID（技術情報）」「この関係のID（技術情報）」と、何のIDかを名前で示す。

## 実装境界

- 引き継いだ自分の分（`ownShare`）の欄は、すでにその欄の中で開くので変えない。検索の条件は同じものを使う。
- 訂正の欄・出典・履歴の中身は変えない。置き場所だけが右の欄から行の下へ移る。

## 検証

- `tests/ui/graph-registry-view.test.mjs` で、行の下に開くこと・見出し・閉じる・関係をたどる・一覧に無い記録・右の欄の案内・すぐ反映・変換中に反映しないこと・札と「すべて外す」・有効時点・要約の表示を確かめる。
- 組織版と同じ枠・CSS・応答の形で、実ブラウザ（幅1440pxと1000px）の変更前後を比べる。
