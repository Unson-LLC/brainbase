# 世界の町の札（要確認・一部だけ読めた）は意味を添え、押すと理由と次にすることが分かる

## 利用者成果

世界を開いた本人として、町に付いた札を見たら、それが何を意味するかが分かりたい。押したら、なぜそうなっているのか（実際の原因）と、どこで何をすれば解消するのかが分かりたい。

## 背景

- 2026-10-16、佐藤が組織版の世界で指摘した（UX点検 3-5・3-6）。町に付く「要確認」と「一部だけ読めた」（例: BAAO、Brainbase）が何を意味し、何をすれば解消するのか分からない。
- 共通コア（develop `b6f9bf66e`）で再現した原因:
  - 札は町の名札の中の飾りで、押すと名札と同じく区画に入るだけ。札そのものの意味は出ない。
  - 「要確認 N」が「未完了の仕事のうち、タスクの記録に抜けがある件数」であることは区画の中でしか分からず、抜けの種類ごとに何を直せばよいかは1件ずつ開かないと出ない。
  - 「一部だけ読めた」の理由（組織版 `readWorldTasks` が付ける `codes_not_permitted`＝タスクの権限外の案件を読んでいない、`page_limit_reached`＝案件ごとに200件で打ち切った）は、区画の中の「出典と時点」にしか出ない。世界の左上の「仕事が一部だけ読めた事業 2件」には理由も行き先もない。
- 前提台帳 P9（未接続や不明を0件や空に見せない。推測で埋めない）、P17（平常時は俯瞰し、例外だけを目立たせて既存の画面へ降りる）、P16・D8（直しはOSSの共通UIで行う）。同日の OSS #803（押せない所を直す）と #801（内部IDを画面から外す）の上に積む。

## 受入条件

- [x] AC-01: 町の札は意味を短く添える。「要確認 N：記録に抜け」「一部だけ読めた：権限外の案件あり」「一部だけ読めた：件数が上限」のように、要確認と読み込みの状態を別の札に分ける。読み込みの理由の言葉は、ホストが記録した理由（`summary.reason`）からだけ出し、知らない理由や理由のないときは言葉を付けない。
- [x] AC-02: 札を押すと、区画に入らずに右の引き出しが開き、「札の意味と、次にすること」を出す。
  - 要確認: 読めた未完了の仕事のうち何件に、どの種類の抜けが何件あるか。種類ごとに直し方（タスクの担当欄に登録する、出典リンクを足す、状態か見直し予定を更新する等）。仕事が止まっている・遅れているという意味ではないこと。
  - 一部だけ読めた・仕事を読めない: 読み込みの時点、理由（記録された理由の文。無ければ「理由は記録されていません」）、件数の意味（読めた範囲・0件とは限らない）、次にすること（権限外なら案件のタスクを見る権限が要り、組織の管理者が付けること。上限なら直す操作はないこと。応答なし・接続できないなら開き直すと読み直すこと。理由から分からないときはそう書く）。
- [x] AC-03: 引き出しの抜けの種類を押すと、その事業の区画に入り、その種類の仕事を一覧にして街の中で濃く出す。「区画に入って仕事を見る」で区画に入る。
- [x] AC-04: 区画の入口の一覧も同じ言葉で札を出し、札のある事業には「札の意味 ›」を置く（キーボードで同じ説明へ行ける）。
- [x] AC-05: 世界の左上の「仕事が一部だけ読めた事業 N件」に理由の短い言葉を添え、「理由を見る」で区画の入口を開く。区画の中の「仕事：一部だけ読めた」にも理由の短い言葉を添える。区画の詳細の「把握できていないこと」の種類ごとにも直し方を添える。
- [x] AC-06: 札の名前（町の名札）を押したときは今までどおり区画に入る。札にポインタを載せると名札の案内が「札の意味を見る」に変わる。

- 試験: `tests/ui/world-sign-meaning.test.mjs`（5件。変更前のコードでは5件とも落ちる）。文言を変えた既存試験3件（`world-work-rail`・`world-canvas-notes`・`world-canvas-view`）を新しい言葉に合わせた。試験一式（208ファイル・2417件）合格。
- 実ブラウザ（Chrome、1440×900）: 組織版と同じ引数（`presentation: 'canvas'`、組織のGraph、判断は未接続）で、見本の3事業（BAAO＝権限外の案件あり・要確認3、Brainbase＝件数が上限・要確認5、Mana＝すべて読めた）を変更前と変更後で並べて押した。
  - 変更前: 札は「要確認 3（一部だけ読めた）」。押すと区画に入り、左上は「仕事：一部だけ読めた」で理由なし。入口の一覧は「要確認 3・一部だけ読めた」。
  - 変更後: 札は「要確認 3：記録に抜け」「一部だけ読めた：権限外の案件あり」。押すと町に入らず「札の意味と、次にすること」が開き、抜けの種類と直し方、読み込みの理由と次にすることが出る。入口の一覧に「札の意味 ›」、左上に「（権限外の案件あり・件数が上限）理由を見る」。
