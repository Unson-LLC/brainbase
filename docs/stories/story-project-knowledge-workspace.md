# プロジェクトの目的と関係する情報を根拠までたどれる

利用者は、プロジェクトを開くと目的、扱う情報、関係者、判断と根拠を同じ場所からたどり、記録の不足も判別できる。

## Controller
NORMAL。直近の共通画面StoryとMana画面分離を確認した。既存画面は登録確認に限られ、プロジェクトを理解する成果が不足している。既存のGraph画面を拡張し、独立した台帳や業務別画面を増設しない。任意の型と関係を残し、組織版はこの部品を利用する。

## 受入条件
- AC-01: 選択したプロジェクトで、目的・状態・情報の種類・関係者・判断・出典・取得時点を実データから表示する。未記録と取得失敗を件数ゼロに変換しない。
- AC-02: Sigma.jsによる2Dグラフと一覧から同じ対象を選び、関係の意味と根拠を確認できる。未知の型を隠さない。
- AC-03: 既存の訂正権限と個人の共有情報の境界を維持する。表示だけで書き込みを行わない。
- AC-04: 外部CDNなしで配布する。描画失敗時にも一覧が残る。画面切替時に描画資源を解放する。
- AC-05: 組織版は共通部品を固定版で利用する。本番到達はCIと区別して確認する。

未決の判断・待ち・目的の関係の新設は、この表示変更では行わない。現在取得できる記録を表示し、取得できない内容を明示する。
