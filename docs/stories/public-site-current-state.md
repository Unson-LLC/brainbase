# 公開サイトで現在のBrainbaseを迷わず理解できる

## User Story

Brainbaseを初めて見る利用者として、最初の画面で価値と次の行動を理解し、公開版と組織版の現在地を古いversion表記や崩れたレイアウトに邪魔されず確認したい。

## Acceptance Criteria

- デスクトップとモバイルのheroで、見出し・説明・画像・CTAが重ならず、読む順序が「価値 → 説明 → 行動 → 図」になる。
- 最初のCTAは「試す」と「全体像を見る」の2つに絞り、実装状況は本文から確認できる。
- 現在の状態ページは`package.json`のrelease versionと一致し、検証スクリプトも固定versionではなく同じ正本を参照する。
- 組織版ページは、公開OSSとの違い、現在提供している範囲、計画中の範囲を区別する。
- `docs:check`、`docs:build`、`docs:smoke`が通り、主要ページをデスクトップ幅とモバイル幅で確認できる。

## Out of Scope

- 公開OSSに組織版runtimeや認証機能を追加すること
- Organization先行案内フォームの送信契約を変更すること
- 未公開機能を実装済みとして説明すること
