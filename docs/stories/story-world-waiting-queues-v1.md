# 世界の「あなたを待っている」に、ほかの待ち行列の件数を外から渡す

## 利用者成果

朝に世界を開く本人として、判断だけでなく、振り分けを待っている会議のような「自分が決めるもの」の件数も同じ場所で見て、押してその画面へ降りたい。

## 背景

- 前提台帳 P17（2026-10-12、D9）は、世界の待っている一覧に「振り分け待ちの会議」を加えると決めた。
- 世界の部品はOSSにあり、組織版の会議の振り分けを知らない。部品は会議を知らずに、待ち行列の名前・件数・降り口だけを受け取る。

## 受入条件

- [ ] AC-01: `createWorldView` の新しい任意の `waitingQueues` に、`{ status: 'available', queues: [{ id, label, count, href, link_label? }] }` を返す関数を渡すと、件数が1以上の待ち行列ごとに「待っている」の注記を `「{label} {count}件」` と降り口のリンク付きで出す。
- [ ] AC-02: 件数が0の待ち行列は出さない。
- [ ] AC-03: 読めない（関数が失敗する、`status` が `available` でない、件数が整数でない）待ち行列は、0件と出さずに「読めない。0件とは確認できません」と出す。
- [ ] AC-04: `waitingQueues` を渡さないときは、今までと同じ画面になる。
- [ ] AC-05: 降り口は `https:` かホスト内のリンク（`/…`, `?…`。事業の出口と同じ判定）だけを受け付け、それ以外のリンクは付けない。
- [ ] AC-06: キャンバス表示と標準表示の両方で出す。

## 範囲外

- 世界から直接振り分けること。振り分けは降りた先の画面で行う。
