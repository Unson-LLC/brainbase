# プロジェクトを1秒以内に開き、情報を後から読む

利用者がプロジェクトを選ぶと、通信の完了を待たずに選択先の名前と読み込み状態を表示し、現在どこにいるか分かる。

## 受入条件
- AC-01: 既知のプロジェクトを選択してから1秒以内に中央の個別プロジェクト見出しと読み込み状態が表示される。Graph一覧・詳細・補足情報の通信完了に依存しない。
- AC-02: 詳細・補足情報は取得後に表示する。取得失敗を未登録や0件として表示しない。
- AC-03: 連続選択、画面破棄後の遅い応答で別プロジェクトの内容を表示しない。
- AC-04: グラフ描画には既存のSigma.jsを維持する。権限と訂正処理の境界は変更しない。
- AC-05: 通信を保留した回帰テストと、本番のブラウザ内のクリックから表示までの計測を分けて確認する。

## 根拠
2026-09-29 本番のBrainbase選択は、操作開始から見出しまで13.065秒（自動操作の通信時間1.698秒を含む）。中央の個別表示はGraph詳細が成功するまで作られていない。
