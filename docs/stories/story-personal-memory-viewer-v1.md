# 本人が、Brainbaseの覚えている自分を確かめ、どの判断に効いたかが分かる

本人として、Brainbaseが自分について何を覚えているか（個人KG）を、画面で一覧して確かめたい。その記憶が今も有効か、どこから来たか、どの判断に効いたかも知りたい。古い記憶や誤った記憶に、自分で気づける状態を到達点とする。

2026-10-17の時点で、個人KGの中身を本人が見られる画面は無い。判断の履歴は「個人KGを使ったか」と件数だけを出す（`story-judgment-history-frame-basis-v1` AC-06）。読む経路はMCPの `search_personal_kg` だけである。候補の確認では候補の中身が見えるのに、昇格した後の記憶はどこにも出ない。

画面の前提は、brainbase-project の前提台帳 D15（「あなたの記憶」）と、情報設計 `docs/design/personal-memory-viewer-2026-10-17/` に置く。

## 開発モードの決定

この変更は **EXTENSION** とする。新しい正本は作らない。OSSの手元の正本 `personal-kg.jsonl` と、判断の記録が持つ個人KGの参照（`kind=personal_knowledge`）を読む。画面はOSSの共通UI部品として作り、組織版はそれを組み込む（P16）。

## 受入条件

- AC-01: 領域「情報と関係」に、タブ「あなたの記憶」を置く。並びは、情報と関係／人と会社／あなたの記憶／候補の確認とする。
- AC-02: 画面の見出しの下に、「この画面はあなただけが見ています。組織の管理者も読めません。」を常に出す。組織版のホストが本人以外と判定したときは、タブを出さない。URLで直接開いたときは「この画面は本人だけが見られます」と出し、記憶を読まない。
- AC-03: 一覧は1行に1つの記憶とし、種類・本文の冒頭（2行まで）・出どころ・使われた判断の件数・更新を出す。題名を推測で付けない。並びは更新の新しい順とする。
- AC-04: 絞り込みは、種類・状態・出どころの組織・語句とし、札で並べる。札ごとに外せるようにし、「すべて外す」を置く。状態の既定は「有効」とする。かけた絞り込みはURLに残す。
- AC-05: 置き換え済み・取り消しの記憶は、状態の絞り込みで選んだときだけ出す。出すときは状態の札を付け、今の記憶に見せない。状態の記録が無い書き手（OSSの手元）の記憶は「状態の記録なし」とし、「有効」と書かない。
- AC-06: 詳細は、本文 → 状態の移り変わり → 出どころ → AIが使う範囲 → この記憶を使った判断 → 記録の詳細（折りたたみ）の順に出す。出どころで決められないものは「不明」とする。ログイン中の組織から付いたものには「推定」の印を付ける。
- AC-07: 「この記憶を使った判断」は、判断の記録の参照（`kind=personal_knowledge`）から逆に引き、新しい順に5件と「すべて見る」を出す。各行は判断の履歴の1件（`?screen=value-proofs&decision=…`）を開く。0件のときは「まだ使われていない」とし、読めなかったときは「確認できない」と出して、0件に見せない。
- AC-08: 判断の履歴の区画「本人の考え」で、閲覧者が本人のときだけ、使った記憶の本文の冒頭をリンクで出す。リンクは「あなたの記憶」の詳細を開く。本人以外には、これまでどおり件数だけを出す（AC-06 of `story-judgment-history-frame-basis-v1` は、本人以外の閲覧に限って保つ）。
- AC-09: 0件（確認済み）と、読めなかった場合を区別する。0件は「まだ記憶はありません」と出し、候補の確認への行き先を添える。読めないときは理由と再試行を出す。読み込みの途中は、前の表示を保つ。
- AC-10: 初版は読むだけとする。訂正・取り消し・書き出しの操作を置かない。
- AC-11: OSSの手元のWebホストは、`personal-kg.jsonl` を手元のトークンで守られた読み取り経路から返す。記憶の本文を、URLのクエリ・ログ・外部の送信先に載せない。
- AC-12: 組織版はこの共通UIをそのまま使い、記憶の読み取りはホストが渡す関数で行う。組織版の中でコピーや作り直しをしない（P16）。

## 対象外

- 正本API（brainbase-unson）に本人専用の一覧の読み取りを足す変更。組織版のホストの読み取り関数は、それを使う後続のStoryで行う。
- 本人の置き場の移行（ADR-023 段2）。画面は読む先が替わっても変えない。
- 訂正・取り消し・書き出しの操作。本人の置き場を消す・書き出す範囲の決定（ADR-023の未決）と一緒に決める。
- 世界の「記憶の状態」からこの画面へ降りる導線。この画面ができた後に足す。
