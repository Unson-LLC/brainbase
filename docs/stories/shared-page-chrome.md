# Story: 同じページヘッダーと必要時だけの詳細を使う

ページによってヘッダーの厚さや詳細の占有幅が違い、一覧を見渡しにくい。共通のタイトルバーと右drawerを使い、本文と画面固有操作へ集中できるようにする。

## 受入条件

- タイトルのみ44pxの固定バー。世界はヘッダーなし。
- 常設右列なし。知識/議事録/ホスト詳細は選択時にdrawer、既存タスク/判断drawerを再利用。
- close/Escape/背景、focus復帰、非同期更新後のclosed維持、画面破棄を保証。
- フィルター、追加/作成、保存・失敗・再試行・readbackは保持する。
- 組織の認証・権限・テナント・データ契約は変更しない。
- [共通パーツの規約](../specs/oss-common-ui-spec.md)と関係repoの入口参照を更新する。

互換オプションと共通パーツAPI、所有境界、検証は上記Specを正本とする。
