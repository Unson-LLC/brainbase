# レガシー運用記録の整合仕様

1. Web棚卸しはWiki MCP検索を現役と記さず、Device OAuthのproviderを固定しない。
2. 本番読戻しは対象SHA、確認日、HTTP結果を記載し、過去の検証と区別する。
3. SNSジョブは専用Labelだけを対象に停止状態を確認する。共有サービス・保存データ・秘密情報は変更しない。
4. 現行merge手順は通常PR経路へ更新済みであることを確認し、変更しない。古い個人checkoutの退役session lifecycle API手順を復活させない。
5. 文書変更は参照先・コードとの照合、diff checkで検証する。実機の観測は全ホストの不在証明に拡張しない。
