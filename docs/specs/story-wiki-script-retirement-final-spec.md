# 退役Wiki書込みスクリプトSpec

## 契約

1. `scripts/merge-codex-to-wiki.js` は旧Codex内容をWikiへコピーするため、ファイルごと除去する。
2. `scripts/reorganize-wiki.sh` は旧Wikiツリーを移動・削除するため、ファイルごと除去する。
3. `scripts/create-story-records-from-wiki.js` は旧WikiからNocoDBへStoryを書き込むため、ファイルごと除去する。
4. `scripts/migrate-graphdb-to-wiki.js` と `scripts/populate-wiki-pages.js` は保護データの棚卸し用途を残す。ただし、`--dry-run` なしでは終了コード1で停止し、DB接続・ファイル書込み・データ変更を行わない。
5. 対象ファイルの削除はリポジトリ内のコードだけに限定し、保存データと本番反映には影響させない。

## 検証

- 削除対象3ファイルが存在せず、サーバー・CLI・package scriptの実行元から参照されない。歴史的な文書や移行ヘルプの文字列は、実行元とは区別して棚卸しに残す。
- 保持対象2スクリプトは、空のfixtureと接続不能な環境で `--dry-run` なしを実行しても、退役エラーを先に返す。
- 保持対象2スクリプトの `--dry-run` は、保護データの棚卸しに必要な読み取りだけを行い、ファイル書込み・DB更新を行わない境界を保つ。読み取り失敗は成功や不在に変換しない。
- 既存のWiki退役関連テストと対象テストが成功する。

## 境界・根拠

Graphifyの初回結果は対象4スクリプトを抽出したが、鮮度・影響は `unknown`、シェルと文書は未収録だった。したがって、削除判断はGraphifyの件数ではなく、直接参照検索と対象テストで補完する。今回の変更は保存データの不存在や本番反映を証明しない。
