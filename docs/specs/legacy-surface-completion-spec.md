# 退役操作面の残存整理

## 検証する振る舞い

1. 配信に必要なdevice認証資材は200、旧UI入口は404/410を維持する。
2. 現役利用のない旧ブラウザ資材はGitツリーにも静的配信にも残らない。追加の死んだ資材が紛れれば境界テストが失敗する。
3. 残るソース・テスト・設定から削除先を読み込まない。専用UIテストの削除で現役API/認証のテストまで失わない。
4. session状態の保存、復元、監視、削除をBrainbaseが再開しない。既存DB/JSONには触れない。
5. 必要な互換処理は利用者と所有者を明示し、単にテストが存在するだけでは現役利用と判定しない。

現行ソースの依存確認と実Expressの配信テストを組み合わせる。Graphifyがpartial/unknownの場合は無影響の証明として使わない。Graph検索取得失敗を組織判断の不存在にしない。
