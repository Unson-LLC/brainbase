# 組織版リリース記録の監査手順（Spec）

状態: 手順案。組織版の正式記録への反映は別途レビューする。

この Spec は照合キーと失敗条件、候補のレビュー手順を定める。記録の置き場は対象リポジトリの既存記録に従い、この PR では指定しない。`docs/releases` への追記確認の実施や正式記録への反映は、この Spec の追加だけでは完了しない。

対象リポジトリの既定ブランチにマージされた PR を全ページ取得し、既存リリース記録と PR 番号・マージ日時・コミット SHA・記録月で照合する。重複、余分な記録、欠落を検知し、欠落があれば失敗として報告する。取得中の更新を考慮し、反映直前に再取得する。

欠落分はレビュー待ちの候補として扱い、概要・互換性・利用者操作を原 PR と照合する。人手レビューを完了した候補だけを正式記録に投影する。内容が未確認の過去分は推定で埋めない。

組織固有の件数、日時、担当者、内部ブランチ、監査結果と候補データは公開 OSS 文書に含めず、対象リポジトリ内で管理する。マージ履歴は配備や公開承認の証拠にはしない。
