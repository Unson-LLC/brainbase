# Spec: 日次ルーティンレポートの読みやすさ

- INV-1: `ohayo`、`oyasumi`、`retro` の正規化結果は操作アクションを持たない。
- INV-2: 項目の見出しは `title`、`name`、`subject`、短い本文の順で決め、欠損時にも `Untitled`を生成しない。
- INV-3: 短い本文を見出しへ昇格した場合は重複表示せず、長い本文は通常ウェイトの本文として表示する。
- INV-4: 判断候補の定型フィールドは日本語ラベルの行へ分解し、一塊の太字文章にしない。
- INV-5: おはようの旧 `priorityTasks` は状態に応じた4区分へ正規化する。
- INV-6: HTML生成後に不要な操作欄、`Untitled`、空の操作用スクリプトを含めない。
- INV-7: リンクの安全化とHTMLエスケープは既存契約を維持する。
- INV-8: 同一内容の項目はセクション内で重複表示しない。
- INV-9: 判断候補の見出しは判断文から短く生成し、「判断」「再利用できる考え方」を常時表示、背景と適用条件を折りたたむ。
- INV-10: 全項目で同じ状態はセクション見出しへ集約し、項目ごとに繰り返さない。空セクションはHTMLへ表示しない。
- INV-11: レトロの各セクションは先頭3件を通常表示し、4件目以降を件数付きの開閉領域へまとめる。
- INV-12: 項目見出しは中程度のウェイトとし、参照先も説明もない証跡はHTMLへ表示しない。
- INV-13: 冒頭に表示中の項目数・セクション数と、各セクションへ移動できる目次を表示する。空セクションは集計にも目次にも含めない。
- INV-14: 各セクションは安定したアンカーを持ち、デスクトップではセクション見出しを追従表示する。狭い画面では通常フローへ戻す。
- INV-15: 表示順はモードごとの目的に合わせ、おはようは判断・到達点、おやすみは失敗・持ち越し・判断、レトロは結果・仕組み変更を情報源や補足より先に置く。
- INV-16: 冒頭の重点領域は通常セクションと視覚的に区別し、左ナビゲーションには重点ラベルと件数を併記する。
- INV-17: 長い情報源セクションは先頭4件、重点領域とレトロは先頭3件を表示し、残りを件数付き開閉領域へまとめる。
- INV-18: モードごとに一つのアクセント色だけを使い、本文・状態・証跡の意味は色だけに依存しない。

検証: `tests/unit/daily-ops-report.test.js` と3モードのHTML再生成後の文字列検査。
