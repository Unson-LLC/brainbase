# UX-20261008-01 証拠参照表示 Spec

## 表示契約

`outcome.evidence_refs[]`は、保存された証拠参照を画面用の文字列へ整形する。通常の契約値では、ラベルがあればラベルと種類・参照値を、ラベルが無ければ種類と参照値を表示する。種類・参照値が構造化されていても、その中の記録済みの`label`、`name`、`title`、`kind`、`type`、`ref`、`id`、`version`等の識別値を人が読める文字列へまとめる。

識別値が無い、空のオブジェクト、nullなどは、証拠欄では次の固定文言にする。

```text
証拠の識別情報は未確認
```

`execution.artifact_refs[]`にも同じ整形を使い、識別値が無い場合は`成果物の識別情報は未確認`とする。どちらもリンクへ変換しない。

## 状態の保持

- `status === "verified"`だけを「確認済み」と表示する。
- それ以外、または状態を読めない値は「未確認」と表示する。
- 表示上の識別情報を補っても、成果・出典・確認状態を補作しない。

## 回帰条件

- 確認済みと未確認の証拠参照が同じ詳細にあれば、双方の状態が表示される。
- 構造化された種類・参照値、ラベル付き成果物、空の参照、null参照を描画しても`[object Object]`が出ない。
- このSpecの表示から`<a>`要素や任意URLを作らない。
- 対象実装は`ui/value-proof-review.js`、テストは`tests/ui/value-proof-review.test.mjs`に限定する。
