# Skillsと常時指示の整理

対象: AGENTS.md / CLAUDE.md、および監査で選んだ開発用Skillの入口。

## 振る舞い

- 軽微な変更では、その対象と実際に必要な検証だけを選べる。
- 不具合では期待値と観測を分け、原因に対応する調査を選び、修正後に元の症状を検証する。間欠障害で100%再現を要求しない。
- Skillの新規作成・更新では短い起動条件と必要時参照を設計する。一般的な説明や作成手順の重複を増やさない。
- Git操作では対象branchと変更を確認し、承認済み範囲を最後まで進める。古い固定checkoutの切替・再起動を一律要求しない。
- テストは変更の不変条件を観測できる最小の層を選ぶ。実測のないカバレッジや全テストの安全性を断定しない。

## 不変条件と検証

- 権限や機密情報、外部送信、既存変更保護の境界は維持する。
- managed VibePro block、Runtime Host、配布プログラムの契約は変更しない。
- `cmp -s CLAUDE.md AGENTS.md`、200行以内、`git diff --check`、変更Skillのfrontmatterと相対リンクを検証する。
- 既存 `tests/unit/vibepro-minimal-core-contract.test.js` を実行する。
- 監査報告に固定シナリオでの文書上の適用判定と未測定範囲を残す。文書検査をモデルの実動作実験とは呼ばない。
