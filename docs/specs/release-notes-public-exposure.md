# RQ-139 リリースノートの外部公開範囲（提案）

状態: Spec のみ、公開責任者の範囲決定待ち。

OSS のローカル抽出下書きと履歴照合、組織版の内部リリース記録を対象とする。外部閲覧エンドポイント・認証変更・公開対象の自動選別は実装しない。

決定事項: 対象読者、公開する版とフィールド、候補版の扱い、個人・顧客情報の審査責任者、配備先、更新承認と取り下げ手順。組織版の main マージは本番反映や公開承認を意味しない。

承認後の実装では、未承認の記録を既定で非公開とし、承認済みの最小情報のみを表示する。機密情報除去・版と公開状態の一致・未承認記録へのアクセス拒否・取り下げを検証する。公開・配備は別途承認する。
