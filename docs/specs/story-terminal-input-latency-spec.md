# Terminal input latency specification

## Scope

- `public/modules/core/terminal-transport-client.js`
- `public/modules/core/input-telemetry.js`
- `tests/unit/terminal-transport-client.test.js`
- `tests/server/services/terminal-transport-service.test.js`

## Invariants

- INV-1: Optimistic Backspace rendering may only erase text tracked in
  `_pendingEchoText`.
- INV-2: Optimistic Backspace rendering may only erase printable ASCII
  characters, which are single-cell in the terminal.
- INV-3: Every Backspace input is still dispatched to the WebSocket terminal
  transport when input is allowed.
- INV-4: Non-ASCII pending echo is left for the PTY echo path to render.
- INV-5: A local erase must emit a measurable client telemetry marker.

## Contracts

- C-1: `TerminalTransportClient._applyLocalEcho('\x7f')` delegates to local
  Backspace handling before WebSocket dispatch continues.
- C-2: `_applyLocalBackspaceEcho()` removes exactly one trailing ASCII character
  from `_pendingEchoText` and writes `\b \b` to xterm.
- C-3: `_applyLocalBackspaceEcho()` reschedules or clears pending echo state
  according to whether `_pendingEchoText` remains non-empty.
- C-4: `_applyLocalBackspaceEcho()` increments
  `inputTelemetry.inc('localBackspaceEcho')` only when a local erase is applied.
- C-5: `_canLocallyErasePendingEcho()` returns false for empty pending echo and
  for non-ASCII trailing characters.

## Scenarios

- S-1: Given `_pendingEchoText` ends with `c`, when Backspace is sent, then xterm
  receives `\b \b`, `_pendingEchoText` loses `c`, telemetry records
  `localBackspaceEcho`, and the WebSocket receives `\x7f`.
- S-2: Given no pending local echo, when Backspace is sent, then xterm receives
  no local write and the WebSocket receives `\x7f`.
- S-3: Given `_pendingEchoText` ends with a non-ASCII character, when Backspace is
  sent, then xterm receives no local write, pending echo is unchanged, and the
  WebSocket receives `\x7f`.

## Anti-patterns

- AP-1: Locally deleting arbitrary terminal output that was not generated by
  local echo.
- AP-2: Locally deleting wide or combining characters with a one-cell erase
  sequence.
- AP-3: Treating local UI erase as a substitute for sending Backspace to tmux.
