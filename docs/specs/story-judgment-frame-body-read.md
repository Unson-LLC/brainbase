# 判断の枠組みの本文取得契約

`@unson/brainbase-mcp/judgment-frame` は `brainbase_judgment_frame_read` のtool定義とhandlerを提供する。入力は現在の `catalog_digest` と、重複のないkind/refの選択1〜24件。

- 呼出し側が認可済みのloadRecordsを渡し、三種類の現在のカタログを再構成して入力digestを照合する。
- 選択した哲学・目的・世界モデルのpayload全体を正規JSON本文として返し、本文digest、版とその由来、適用範囲とその由来を返す。
- 版のない本文は本文digestを版に使う。適用範囲が未記載なら未設定と明示し、認可範囲を意味的な適用範囲に置き換えない。
- 古いカタログ、不明な参照、重複、ラベルだけの世界モデル、取得失敗、切詰めの可能性があるページでは成功しない。
- 既存のカタログ・記録APIとの互換性を維持する。Graphへの書込みはしない。

取得済み本文と採用案への適用を結び付ける完了判定はHostの責務。参照の選択や不適用理由の意味的妥当性はこのAPIでは保証しない。
