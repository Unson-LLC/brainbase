# Acceptance contract

- Columns: purpose, recorded state, outstanding checks, check date. Dates and missing data come from records; no invented progress or fabricated samples.
- Row click or keyboard activation opens a native dialog with achievement conditions, evidence and provenance. Original fields, status, IDs, revisions and digests remain in optional details. Escape closes and restores focus. Reload/destroy closes stale dialogs.
- Philosophy starts open; world models start closed. Section headings use the shared h2 size. Help appears above its control on hover/focus and supports click and Escape.
- Notification descriptors preserve source failures and retry. Partial coverage is disclosed, never converted to full success or zero records. Notification details start closed.
- Optional compact owner view keeps read-only and bundle provenance; unknown and failed reads remain distinct from confirmed absence. Destroy ignores late responses.
- Shared native scrollbars use 800ms inactivity and a 450ms ease fade. Listener and timers are disposed; forced colors use standard native colors and reduced motion disables the transition.

Validation: foundation overview, owner-private view, workspace kit, native scrollbar and local Web host tests; host integration and real browser verification.
