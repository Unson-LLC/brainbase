# 小さな改修でも依存関係の見落としを減らす

実装担当として、変更規模を理由に影響調査を省略せず、利用可能なGraphifyを軽く参照して、読むコードと必要なテストを選びたい。

## 受け入れ条件

- engineeringの実装判断DAGは、観測後・仮説前にGraphify参照手順を渡す。
- インストール済みなら変更規模によらず軽量参照する。再生成・深い探索は不足時だけ行う。
- 同じ対象・ソース・グラフの条件では結果を再利用できる。
- グラフ欠落、鮮度不明、解析不足、失敗を影響なしや検証成功に変換しない。
- 非実装の回答・調査に必須工程を追加せず、PRゲートやマージ権限を増やさない。
