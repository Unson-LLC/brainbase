# Story: Stop Hook の内部修復文を利用者に見せない

## 利用者価値

Brainbase の判断 Hook が介入しても、利用者には回答に必要な内容だけが見え、内部の監査手順や矛盾した指示を読まされない。

## 受入条件

1. 操作を伴わない、または読み取りだけの低リスク説明回答が engineering または operations に分類されても、証拠収集を要求する DAG ではなく `direct.v1` を選ぶ。
2. 調査、診断、設計、レビュー、操作では従来どおり各ドメインの判断 DAG を選ぶ。
3. Stop の修復理由に、Host が別表示する監査行や「最終回答の先頭へ追加する」という内部指示を含めない。
4. 必須ナレッジ参照、判断根拠、権限境界の不足は引き続き Stop で修復する。
5. 書き込み・外部操作・高リスクの回答では従来の判断証拠契約を維持する。

## 対象外

- Host が別表示する監査内容そのものの変更
- 調査・実装ターンの証拠要件の緩和
- Codex Desktop の `<hook_prompt>` 包装処理の変更
