# 判断の結果を、使った世界モデルへ書き戻す

利用者として、AIが世界モデルを予測に使って判断したあと、実際の結果が予測を支持したか反証したかを、その世界モデルに条件付きで残してほしい。次の判断では、その記録が一覧に見え、反証された世界モデルに頼る案は人間へ戻ってほしい。ある施設で得た反証を、別の施設や次の判断で同じ探索を繰り返さないために使いたい（ADR-014 F6・F5）。

受入条件は [Spec](../../../specs/story-judgment-model-outcome-feedback.md) に記す。記録できることと、支持・反証の判定が意味的に正しいことは分けて扱う。世界モデルの採否や検証済みへの格上げは人間が決める。
