# 議事録ページの見直し

台帳 UUID: 10e31eef-21ee-4e83-9da5-0810e2b82980

依頼は佐藤さん（2026-10-14）。正式な仕様は Designer の 2026-10-14 16:40 版で、DevDirector が 17:09 に見た目を確定した。寸法と文言は html と design.md、主色は藍 `#0F2A43`。完成形の画像は `01-minutes-list-gen.png`、`02-version-readonly-gen.png`、`03-calendar-to-minutes-gen.png`。

実装先は `ui/meeting-minutes.js` と `ui/meeting-minutes.css`。予定と議事録の相互リンク（受け入れ条件 9・10・11）は、会議に予定 id があるかを Maintainer が調査中のため今回の実装対象外。

作った人は正本の `MinutesVersionRecord.created_actor_id`、確認した人は `confirmation.actor_id` と `confirmed_at`。どちらも主体の ID で、詳細の `get_meeting` から渡せる。表示名の別フィールドは無い。ID が無い投影では「作成者は未記録」。

## 受け入れ条件

- Given 日時の違う会議が複数ある, When 議事録ページを開く, Then 会議の日時が新しい順に並び、今日の「梅田さん定例 議事録（下書き）」が一番上の「今日」のまとまりにある。
- Given scheduled_at が無いが予定や版の日時がある, Then 代わりの日時で並び、行には「日時未登録・取り込み {日付}」と出て、会議の日時だとは見せない。
- Given 日時がまったく無い会議, Then 一番下の「会議の日時が未登録」にまとまり、その中は取り込んだ日の新しい順に並ぶ。
- Given 議事録が1件だけの会議, Then 行に「1件の議事録」とは出ない。
- Given 確認されていない最新版, Then 状態は「確認待ち」と出て、「未確認」とは出ない。確認済みなら、詳細に確認した日時と人が出る。
- Given 版が2つ以上ある, When 古い版を選ぶ, Then 「古い版を表示しています。最新は第n版…」と［最新の版を見る］が出る。
- Given 編集できない人, When 議事録を開く, Then 編集できない旨の案内は灰色で1回だけ出て、元の記録へのリンクがある（URLがあるとき）。赤字は出ない。
- Given 確認の権限もない人, Then 確認ボタンは出ず、案内に、確認するのは誰かが書かれている。
- Given 予定とつながった議事録, When 「予定：… を開く」を押す, Then カレンダーがその週で開き、その予定が選ばれている。今回未対応（予定idの有無をMaintainerが調査中）。
- Given カレンダーで議事録のある予定, Then 予定に「議事録」の印があり、詳細の［議事録を開く］で議事録ページのその議事録が選ばれた状態で開く。今回未対応（予定idの有無をMaintainerが調査中）。
- Given つながっていない予定, When 候補の［この予定につなぐ］を押す, Then 予定の詳細と議事録ページの両方に、つながりが出る。今回未対応（予定idの有無をMaintainerが調査中）。
- Given 本文が Markdown, Then 見出しと箇条書きが整って出て、「#」や「------」の文字は出ない。
- Given 1280×800の画面, Then 一覧で2行の行が10行以上、切れずに見える（01の実測は12行）。
- Given 版の履歴を開く, Then 各版に作成日時・相対表現・作った人（または「作成者は未記録」）・確認した人が出る。
