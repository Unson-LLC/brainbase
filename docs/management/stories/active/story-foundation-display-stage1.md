# 同じ範囲の目的・哲学・世界モデルを確かめる

組織の方針を確認する利用者として、選んだ許可プロジェクトの目的・哲学・世界モデルを「目的と現状」で読み、目指す状態と、まだ確かめられていない点を区別したい。

## 開発モード

NORMAL。2026-10-06に親controllerで一度選択。履歴はorganization #216-218、OSS #677とWorld Model初回案内Storyを確認。累積複雑性の集計・外部利用者成果は未確認。未接続通知を正本のread-only表示へ統合し、DB・集計サービス・組織版の共通UIコピーは追加しない。

## 受入条件

- AC1: 許可されたプロジェクトを明示選択したときだけ、そのscopeの最新immutable Foundationと哲学を同じ画面で読む。会社基礎がprojectにある場合も会社名からscopeを推測しない。
- AC2: 目的の目指す状態・評価の定義・期間・評価者・責任者の未確定を表示する。記録された現状は保存時点の出典付き記述として表示し、登録済み・承認済み・達成済みを混同しない。
- AC3: 哲学の本文、世界モデルの関係・適用条件・不確かさ、草案/仮説/未検証/許可用途を読める。多数のモデルは検索し、一覧は適量ずつ表示できる。
- AC4: 未取得・欠損・認可拒否・API失敗を空/0件/成功へ変えない。scope切替・破棄後に旧レスポンスを表示しない。
- AC5: 共通表示はOSS、組織は認証・許可scope・BFF・mountを所有する。DB書込み、観測実績・判断記録のAPI接続は追加しない。
- AC6: 共通UIの振る舞い、Graph readのscope/history/current ACL、組織BFF境界とscope切替をaffected testsで検証し、1回reviewとPR/CIで確認する。本番表示はデプロイ・実画面確認前には完了と呼ばない。
