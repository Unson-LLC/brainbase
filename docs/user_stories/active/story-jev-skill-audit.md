# Jevを使ってSkillsの修正候補を確認する

利用者として、Skillsや常時指示の見直しにJevの補助チェックを使い、修正候補と判断材料不足を原文の根拠とともに把握したい。

## 受け入れ条件

- 既存のJev実行経路を再利用し、固定した入力・判定基準で実行する。
- 修正候補・現状維持・材料不足・API失敗を区別する。
- 明確な文書、空入力、既存変更の前後を対照にし、結果を原文と照合する。
- 見逃し・保留・未測定の効果を明記し、自動修正や新しい必須ゲートにはしない。
- Skill作成入口から、必要時だけ参照できるチェック方法と実結果へ案内する。

## 開発モード

SIMPLIFICATION。直近のSkills整理StoryとVibeProのJev実験を踏まえ、常駐サービスや新しい評価フレームワークは追加しない。既存APIの限定試行と文書案内に絞る。
