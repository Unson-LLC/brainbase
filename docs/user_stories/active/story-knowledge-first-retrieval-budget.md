利用者として、別の文脈確認に時間がかかっても最初の知識取得を実行でき、取得しなかった場合は未着手と分かる回答を受け取りたい。

## 受け入れ条件

1. lookup作成から120秒以上経過しても、最初の有効な取得計画を受理する。
2. 検索時間予算は最初の有効な取得予約から始まり、保存・再開・再計画で戻らない。不正な計画やfinishで開始しない。
3. 未着手のStopは続行を求める。続行要求・不正計画の回数上限は維持し、有限に未確認で終了する。
4. 未着手・取得中・取得済みをcontextで区別し、不存在や成功と扱わない。
5. 旧保存状態は取得記録または予約がある場合に従来の開始時刻を保守的に使う。終端済みの状態を再開しない。
6. 権限不足、キャンセル、取得回数・再計画・通信再試行の制限を維持する。
