# Story: 組織に紐づくSlackからメンバーを選べる

管理者として、ログイン用Slackとメンバー台帳用Slackが異なる組織でも、組織に紐づく正しいSlackメンバーをメールアドレスで検索・登録したい。

## 受け入れ条件

- 組織のログイン用workspace IDだけでなく、その組織の有効な権限に紐づくworkspace IDを候補にする。
- 候補内で有効なSlack接続が一意なら、その接続からメンバー名とメールアドレスを取得する。
- 候補内に有効な接続が複数ある、または存在しない場合は閉じて失敗する。
- 組織に紐づかないworkspaceの接続は候補に含めない。
- 新規メンバーの`slack_workspace_id`には、実際に参照したSlack接続のworkspace IDを保存する。
