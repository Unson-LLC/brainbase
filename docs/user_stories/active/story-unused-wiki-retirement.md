# 未使用Wikiの実行経路を除去する

利用者は旧Wikiを使っていないと確認した。コード内の参照を実利用と混同せず、残った読取り・同期・補完処理を除去する。Slack認証と現行のGraph等の機能は保持する。

## 受け入れ条件

- Wiki APIは読取りを含め410を返し、DBへ接続しない。
- Wiki CLIは認証読取り・通信・ローカル保存前に退役を通知する。
- 起動時のWikiService生成とportalのWiki補完を除去する。
- MCPはWikiツール・リソースを広告せず、旧呼出しでWikiへ通信しない。
- Slack認証・現行ナレッジ機能の対象テストが成功する。
- DBの保存済みデータ削除、本番反映、別タスクの変更は含めない。

仕様: `docs/specs/unused-wiki-retirement.md`
