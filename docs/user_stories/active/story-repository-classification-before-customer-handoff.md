# Story: 顧客提供前にリポジトリ境界を判定できる

## 利用者価値

Brainbaseを顧客へ提供する担当者として、機能・顧客設定・事実・文書・素材の正本を迷わず判定し、社内固有物や旧ローカル構成を顧客へ誤配布しないようにしたい。

## 受け入れ条件

- 分類方針の本文が、このrepoの `docs/policies/` に一つだけ存在する。
- `brainbase-unson`、`brainbase-organization`、顧客管理repoの責務が明記される。
- 既知の廃止済み配置を新規に追加すると、自動チェックが失敗する。
- Growinの現存成果物を「そのまま提供可能」「移設候補」「未確認」に分けた棚卸しがある。
- 旧 `_codex` を本番の正本として案内するサンプル文書が残らない。

## 対象外

- Growin環境への配備、OAuth認証、受入試験
- 他repoのファイル移動・削除
- Graph、Drive、顧客repoの書き込み
