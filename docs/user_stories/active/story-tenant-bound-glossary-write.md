# Story: テナント境界付き用語登録を失敗時に止める

認証済み利用者として、対象組織・対象プロジェクト・有効期限を満たす資格情報だけで用語を登録し、登録直後にイベントとGraph正本を読み返したい。誤テナントや不完全な資格情報、保存不整合を成功として扱わないためである。

## 受け入れ条件

- 用語・KPIイベントの `actor_person_id` は認証済み主体から設定され、欠落時は書込み前に失敗する。
- 用語登録はイベント、Graphエンティティ、所属エッジを同一トランザクションで読み返し、欠落時はロールバックする。
- テナント固定MCPは組織、許可プロジェクト、有効期限を検査し、不足・不一致をfail-closedにする。
- モックだけでなく実PostgreSQL制約を使う統合テストがある。
